1. Cú pháp Biến và Kiểu dữ liệu cơ bản trong Python

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Python là ngôn ngữ định kiểu động (dynamic typing); biến được khởi tạo tự động khi gán giá trị mà không cần khai báo từ khóa kiểu dữ liệu, tuân thủ quy chuẩn PEP 8 về đặt tên dạng snake_case.
  • Tận dụng Type Hinting (Python 3.11+) khi khai báo các kiểu dữ liệu cơ bản (int, float, str, bool) giúp VS Code gợi ý mã nguồn IntelliSense chính xác và hạn chế sai sót dữ liệu.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Lỗi TypeError do ghép nối chuỗi (str) với số (int/float) trực tiếp thay vì ép kiểu qua hàm str() hoặc dùng f-string.

Bẫy gán lại khác kiểu dữ liệu tự do cho biến đã khai báo làm sai lệch logic thực thi khi biến được truyền qua nhiều hàm xử lý.

Trình diễn trực quan: Cú pháp Biến và Ép kiểu Dữ liệu An toàn trong Python

main.py
LIVE PREVIEW 
def parse_data(raw_input: str) -> dict:
    # Khai báo biến với Type Hinting theo chuẩn PEP 8
    val_int: int = int(raw_input) if raw_input.isdigit() else -1
    is_valid: bool = val_int >= 0
    message: str = f"Xử lý: {val_int}" if is_valid else "Lỗi kiểu dữ liệu"
    return {"value": val_int, "status": is_valid, "msg": message}
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Nhận chuỗi dữ liệu đầu vào hợp lệ: "25"
> 2. Kiểm tra .isdigit() trả về True, chuyển đổi kiểu dữ liệu str -> int thành 25
> 3. Đánh giá is_valid = True và trả về kết quả dạng dictionary chuẩn
Kết quả đánh giá {'value': 25, 'status': True, 'msg': 'Xử lý: 25'}

2. Cấu trúc Điều kiện if-elif-else và Toán tử Logic

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Cấu trúc if-elif-else điều khiển luồng rẽ nhánh của chương trình dựa trên giá trị Boolean (True/False); PEP 8 quy định bắt buộc lùi lề chuẩn 4 dấu cách (4 spaces).
  • Toán tử logic (and, or, not) kết hợp nhiều điều kiện và áp dụng cơ chế Đánh giá ngắn (Short-Circuit Evaluation): dừng kiểm tra ngay khi kết quả toàn bộ biểu thức đã được xác định.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Nhầm lẫn giữa toán tử so sánh (==) và toán tử gán (=), hoặc quên dấu ngoặc đơn () khi kết hợp `and` và `or` dẫn đến sai thứ tự ưu tiên biểu thức.

Bỏ quên dấu hai chấm (:) ở cuối dòng điều kiện hoặc trộn lẫn Tab và Space gây lỗi IndentationError trên môi trường Pyodide / VS Code.

Trình diễn trực quan: Cấu trúc Điều kiện if-elif-else và Toán tử Logic

main.py
LIVE PREVIEW 
def evaluate_discount(age: int, is_member: bool) -> str:
    if age < 0 or age > 120:
        return "Dữ liệu tuổi không hợp lệ"
    elif is_member and age >= 60:
        return "Giảm 50% (Hội viên cao tuổi)"
    elif is_member or age < 12:
        return "Giảm 20% (Ưu đãi tiêu chuẩn)"
    else:
        return "Không giảm giá"
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Kiểm tra biên (65 < 0 or 65 > 120) -> False, chuyển sang nhánh elif đầu tiên
> 2. Kiểm tra (is_member and 65 >= 60) -> True and True -> True
> 3. Khớp điều kiện ưu đãi cao nhất và trả về kết quả ngay lập tức
Kết quả đánh giá Giảm 50% (Hội viên cao tuổi)
