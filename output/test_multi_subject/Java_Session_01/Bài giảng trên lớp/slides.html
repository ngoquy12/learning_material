1. Cấu trúc Lớp, Phương thức main và Kiểu dữ liệu nguyên thủy

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Khai báo lớp (`public class Main`) và phương thức thực thi `public static void main(String[] args)` làm điểm khởi chạy chuẩn (entry point) cho ứng dụng Java 17.
  • Phân biệt 8 kiểu dữ liệu nguyên thủy (Primitive Types: `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`) lưu trực tiếp giá trị trên bộ nhớ Stack để tối ưu hiệu năng.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Biến cục bộ (Local Variables) khai báo trong hàm `main` KHÔNG tự động nhận giá trị mặc định, bắt buộc phải khởi tạo trước khi truy xuất để tránh lỗi biên dịch.

Hiện tượng ép kiểu thu hẹp (Narrowing Casting) gây tràn số (Overflow) khi gán giá trị của kiểu dữ liệu lớn hơn vào kiểu dữ liệu nhỏ hơn mà không kiểm tra vùng giá trị.

Trình diễn trực quan: Cấu trúc Lớp, Phương thức main và Kiểu dữ liệu nguyên thủy

Main.java
LIVE PREVIEW 
public class Main {
    public static void main(String[] args) {
        int input = Integer.parseInt(args.length > 0 ? args[0] : "100");
        byte smallByte = (byte) input; // Ép kiểu thu hẹp
        long calculatedTotal = (long) input * 100_000_000L;
        System.out.println("Byte: " + smallByte + ", Total: " + calculatedTotal);
    }
}
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Đọc tham số args[0] = "100", ép kiểu chuỗi thành số nguyên int input = 100
> 2. Ép kiểu int (100) sang byte: nằm trong khoảng hợp lệ [-128, 127], giá trị được giữ nguyên
> 3. Thực hiện phép tính (long) 100 * 100_000_000L và xuất ra console kết quả chuẩn
Kết quả đánh giá Byte: 100, Total: 10000000000

2. Toán tử So sánh và Câu lệnh rẽ nhánh trong Java

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Toán tử so sánh (==, !=, >, <, >=, <=) trả về giá trị kiểu boolean (true/false), đóng vai trò làm điều kiện kiểm tra trong các cấu trúc rẽ nhánh.
  • Java 17 hỗ trợ cấu trúc rẽ nhánh truyền thống (if-else, switch-case) và Switch Expression cải tiến với cú pháp mũi tên (->), giúp code ngắn gọn, không lo bỏ sót lệnh break và có thể trả về giá trị trực tiếp.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Dùng toán tử == để so sánh nội dung 2 Chuỗi (String) thay vì phương thức .equals(): toán tử == chỉ so sánh địa chỉ ô nhớ (tham chiếu), dẫn đến sai logic khi so sánh dữ liệu chuỗi nhập từ bên ngoài.

Nhầm lẫn giữa toán tử gán (=) và toán tử so sánh bằng (==), hoặc không kiểm tra null trước khi so sánh biến đối tượng dẫn đến ngoại lệ NullPointerException.

Trình diễn trực quan: Toán tử So sánh và Câu lệnh rẽ nhánh trong Java

Main.java
LIVE PREVIEW 
public class Main {
    public static String checkAccess(int age, String role) {
        if (role == null) return "Lỗi: Role null";
        if (age < 0 || age > 120) return "Lỗi: Tuổi không hợp lệ";
        if (age >= 18 && "ADMIN".equalsIgnoreCase(role)) return "Quyền Quản trị";
        return (age >= 18) ? "Quyền Thành viên" : "Từ chối truy cập";
    }
}
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Nhận dữ liệu đầu vào: age = 25, role = "ADMIN"
> 2. Kiểm tra Guard Clause: role != null và age (25) nằm trong khoảng hợp lệ [0, 120]
> 3. Đánh giá điều kiện kết hợp (age >= 18 && "ADMIN".equalsIgnoreCase(role)) -> true
> 4. Trả về kết quả phân quyền chính xác
Kết quả đánh giá Quyền Quản trị
