Global Environment Conflict

Project A (Django v3.2) xung đột với Project B (Django v4.2) làm hỏng toàn bộ hệ thống máy tính.

Giải Pháp Cô Lập

Virtual Environments (venv)

Mỗi dự án sở hữu một môi trường ảo hoàn toàn độc lập với phiên bản thư viện riêng biệt.

INSTALLATION

Cài Đặt Python & Cấu Hình Biến PATH

Tùy Chọn Bắt Buộc

Tải bộ cài chính thức từ python.org và phải đánh dấu chọn Add Python to PATH.

VIRTUAL ENV

Khởi Tạo & Kích Hoạt Môi Trường Ảo (venv)

Lệnh CLI Cốt Lõi

Tạo môi trường ảo bằng python -m venv app_env và kích hoạt bằng file script tương ứng theo hệ điều hành.

Terminal — Create & Activate venv
CLI TERMINAL
PS C:\my_project> python -m venv app_env
PS C:\my_project> .\app_env\Scripts\Activate.ps1
(app_env) PS C:\my_project> python --version
(app_env) Python 3.12.2 [VIRTUAL ENV ACTIVE]
SUMMARY & RECAP

Lưu Ý Lỗi Thường Gặp & Bài Học Tiếp Theo

Lỗi Cấu Hình Phổ Biến & Cách Khắc Phục
KEY TAKEAWAYS
Tránh ModuleNotFoundError bằng cách kích hoạt venv trước khi pip install.
Tránh FileNotFoundError bằng cách chuyển terminal về đúng thư mục chứa file.
Đánh dấu Add Python to PATH giúp chạy lệnh CLI từ bất kỳ đâu.
Môi trường venv cô lập hoàn toàn các thư viện cho từng dự án độc lập.
