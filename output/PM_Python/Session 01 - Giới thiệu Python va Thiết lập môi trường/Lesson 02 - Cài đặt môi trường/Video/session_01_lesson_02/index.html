Cú Pháp Lệnh CLI

Khởi tạo môi trường ảo bằng lệnh python -m venv app_env (Cờ -m chạy module chuẩn venv).

ACTIVATION

Kích Hoạt Môi Trường Ảo & Sửa Lỗi Policy

Kích Hoạt Môi Trường

Chạy script Activate.ps1 (Windows) hoặc source bin/activate (macOS). Mở quyền nếu gặp Execution Policy.

PowerShell / Bash Activation
ACTIVATE SCRIPT
PS C:\my_project> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
PS C:\my_project> .\app_env\Scripts\Activate.ps1
(app_env) PS C:\my_project> pip list
Package Version: pip 24.0, setuptools 69.1

KEY TAKEAWAYS
Tránh ModuleNotFoundError bằng cách kích hoạt venv trước khi pip install.
Tránh FileNotFoundError bằng cách chuyển terminal về đúng thư mục dự án.
Tùy chọn Add Python to PATH là bắt buộc để dùng lệnh CLI.
