Tuy nhiên, tạo xong là chưa đủ, bạn bắt buộc phải kích hoạt môi trường ảo trước khi sử dụng. Trên hệ điều hành Windows PowerShell, bạn chạy file kịch bản bằng lệnh .\app_env\Scripts\Activate.ps1. Nếu gặp lỗi Execution Policy về quyền thực thi, hãy mở PowerShell quyền Admin và chạy Set-ExecutionPolicy RemoteSigned. Còn trên hệ điều hành macOS hoặc Linux, bạn chỉ cần gõ lệnh source app_env/bin/activate. Tên môi trường app_env sẽ xuất hiện ở đầu dòng lệnh báo hiệu kích hoạt thành công.
