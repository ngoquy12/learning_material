## 2. Mô tả & Các bước thực hiện
- **Tài nguyên đầu vào**: Môi trường phát triển git cli 2.45+, github cloud (conventional commits, git flow, semantic branching) và tệp tài nguyên thực hành.

3. Bước 3: Thực hiện lưu vết commit và đẩy/đồng bộ thay đổi lên nhánh làm việc.
