Phân cảnh 05 04:30 - 05:30

Xử lý tập tin đã lỡ track vào Repository với git rm --cached

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Hiển thị Slide 5: Kỹ thuật git rm --cached Cảnh báo sự cố lỡ commit file .env và quy trình gỡ bỏ khỏi Git Index 
# Bước 1: Thêm file .env vào .gitignore
echo ".env" >> .gitignore

# Bước 2: Gỡ bỏ .env khỏi Git index (vẫn giữ file đĩa)
git rm --cached .env

# Đối với thư mục (ví dụ node_modules/)
git rm -r --cached node_modules/

# Bước 3: Commit cập nhật trạng thái mới
git commit -m "chore: remove sensitive .env from tracking"
Lời thoại Teleprompter / : ngắt nhịp ngắn • // : ngắt hơi nghỉ

Một tình huống rất phổ biến trong thực tế / là lập trình viên lỡ commit tập tin .env lên Git trước khi thêm vào .gitignore. // Khi đó, / dù bạn có thêm .env vào .gitignore sau đó, / Git vẫn sẽ tiếp tục theo dõi tập tin này. // Giải pháp ở đây là sử dụng lệnh git rm --cached <file>. // Lệnh này sẽ gỡ bỏ tập tin khỏi Git Index / nhưng giữ nguyên file vật lý trên đĩa cứng của bạn. // Đối với thư mục lớn, / bạn kết hợp thêm cờ -r như lệnh git rm -r --cached node_modules/, / sau đó tạo commit mới để ghi nhận thay đổi. //
