Toán tử số học và toán tử gán

1. Tại sao cần toán tử số học và toán tử gán trong hệ thống ShopeeFood?

Hãy hình dung bạn đang xây dựng mô hình tính toán tài chính cho ứng dụng đặt đồ ăn trực tuyến ShopeeFood. Khi một khách hàng thêm 3 phần cơm tấm có giá 45.000 VNĐ vào giỏ hàng, hệ thống phần mềm phải thực hiện chính xác phép nhân giá tiền với số lượng, cộng thêm 20.000 VNĐ phí giao hàng, khấu trừ 15.000 VNĐ từ mã giảm giá voucher, và cuối cùng tính toán số điểm thưởng tích lũy cộng dồn vào tài khoản người dùng.

Tất cả các phép tính toán giá trị tài chính, cập nhật số dư ví điện tử hay tính tiền lẻ hoàn lại cho khách hàng đều dựa trên nền tảng của Toán tử số học (Arithmetic Operators) và Toán tử gán (Assignment Operators).

Nếu thiếu đi các toán tử này, máy tính sẽ không thể thực hiện xử lý dữ liệu số hay cập nhật trạng thái bộ nhớ RAM, khiến toàn bộ quy trình thanh toán tự động bị ngưng trệ.

2. Cú pháp và cơ chế hoạt động của toán tử số học & toán tử gán

2.1. Cú pháp và giải thích Toán tử số học (Arithmetic Operators)

Toán tử số học được sử dụng để thực hiện các phép tính toán đại số cơ bản và nâng cao giữa các biến hoặc giá trị số trong lập trình Python.

Cú pháp định nghĩa phép tính số học trong Python 
result = operand_a operator operand_b

Chi tiết thành phần cú pháp:

  • operand_a, operand_b: Các toán hạng tham gia tính toán (số nguyên int hoặc số thực float).
  • operator (Toán tử số học): Các ký hiệu toán học bao gồm: + (Cộng), - (Trừ), * (Nhân), / (Chia số thực), // (Chia lấy phần nguyên), % (Chia lấy phần dư), ** (Lũy thừa).
  • result: Biến chứa kết quả thu được sau khi thực hiện phép tính.
Yêu cầu bài toán thực hành:

Tính tổng tiền 3 phần ăn giá 45,000 VNĐ, cộng 20,000 VNĐ phí ship và trừ 15,000 VNĐ voucher giảm giá. 

# 1. Tính tổng giá trị đơn hàng ShopeeFood
unit_price = 45000
quantity = 3
shipping_fee = 20000
discount_voucher = 15000

# 2. Phép tính nhân, cộng, trừ kết hợp
subtotal = unit_price * quantity
total_payment = subtotal + shipping_fee - discount_voucher

print('Tiền hàng:', subtotal, 'VNĐ')
print('Tổng thanh toán:', total_payment, 'VNĐ')

              2.2. Cú pháp và giải thích Toán tử gán phức hợp (Compound
              Assignment Operators)
            

            

              Toán tử gán phức hợp kết hợp phép tính số học với phép gán giá
              trị, giúp viết mã ngắn gọn và cập nhật biến bộ nhớ nhanh chóng
              (như x += 5 tương đương với x = x + 5).
            


            
            

              

                
                  
                  
                  
                  Cú pháp toán tử gán phức hợp trong Python
                
              

              
variable += value   # Tương đương: variable = variable + value
variable -= value   # Tương đương: variable = variable - value
variable *= value   # Tương đương: variable = variable * value
variable /= value   # Tương đương: variable = variable / value

            


            
            

              

                Chi tiết thành phần cú pháp:
              

              
    
                
  • 
                  variable: Biến số đã được khởi tạo trước đó trong bộ nhớ RAM.
                
    • 
                
  • 
                  += (Cộng dồn): Thêm giá trị value vào biến hiện tại.
                
    • 
                
  • 
                  -= (Trừ dồn): Khấu trừ giá trị value khỏi biến hiện tại.
                
    • 
                
  • 
                  *= (Nhân dồn): Nhân biến hiện tại với giá trị value.
                
    • 
              

            


            
            

              

                

                  
                  
                  
                

                
# Khởi tạo điểm thưởng tài khoản ShopeeFood
reward_points = 120
wallet_balance = 500000

# Tích lũy 50 điểm từ đơn hàng vừa hoàn thành
reward_points += 50

# Trừ 140.000 VNĐ tiền đơn hàng vào số dư ví
wallet_balance -= 140000

print('Điểm thưởng mới:', reward_points)
print('Số dư ví còn lại:', wallet_balance, 'VNĐ')

            3. Các ví dụ ứng dụng thực tiễn trong hệ thống ShopeeFood
          


          

            

              3.1. Tính tổng chi phí đơn hàng ShopeeFood bao gồm phụ phí và giảm
              giá
            

            

              Ứng dụng ShopeeFood tính tổng tiền thanh toán cho đơn hàng gồm 2
              ly trà sữa (30,000 VNĐ/ly), phí giao hàng 15,000 VNĐ và áp dụng
              voucher giảm 10% trên tổng tiền hàng.
            


            
            

              

                

                  
                  
                  
                

                
# Khai báo thông tin giá tiền
item_price = 30000
item_qty = 2
shipping_fee = 15000
discount_percent = 0.10

# Tính toán tiền hàng và chiết khấu
subtotal = item_price * item_qty
discount_amount = subtotal * discount_percent
final_amount = (subtotal - discount_amount) + shipping_fee

print('Tiền hàng gốc:', subtotal, 'VNĐ')
print('Số tiền giảm giá:', discount_amount, 'VNĐ')
print('Thành tiền thanh toán:', final_amount, 'VNĐ')

              3.2. Cập nhật tích lũy điểm thưởng và số dư ví bằng toán tử gán
              phức hợp
            

            

              Cập nhật biến trạng thái ví ShopeePay sau khi thanh toán đơn hàng
              thành công, trừ tiền đơn hàng và cộng điểm thưởng tích lũy tương
              ứng 5% giá trị đơn.
            


            
            

              

                

                  
                  
                  
                

                
# Số dư ví ban đầu và điểm thưởng
wallet_balance = 350000
user_points = 80
bill_total = 165000

# Trừ tiền hóa đơn khỏi ví
wallet_balance -= bill_total

# Tích lũy 5% hóa đơn thành điểm thưởng (lấy phần nguyên)
earned_points = int(bill_total * 0.05)
user_points += earned_points

print('Số dư ví sau thanh toán:', wallet_balance, 'VNĐ')
print('Điểm thưởng tích lũy mới:', user_points, 'điểm')

              3.3. Chia tiền hóa đơn nhóm và tính tiền lẻ hoàn lại dư
            

            

              Khi nhóm 4 người cùng nhau chia đều một hóa đơn ăn uống ShopeeFood
              trị giá 355,000 VNĐ, sử dụng phép chia lấy phần nguyên
              // để tính số tiền tròn mỗi người cần trả và phép
              chia lấy dư % để tính số tiền thừa dư ra.
            


            
            

              

                

                  
                  
                  
                

                
# Tổng tiền hóa đơn ăn nhóm và số người
group_bill = 355000
num_people = 4

# Phép chia lấy phần nguyên (Số tiền mỗi người đóng)
share_per_person = group_bill // num_people

# Phép chia lấy phần dư (Số tiền thừa dư ra)
remaining_change = group_bill % num_people

print('Mỗi người đóng:', share_per_person, 'VNĐ')
print('Tiền dư lẻ:', remaining_change, 'VNĐ')

            4. Tổng kết bài học & Các lỗi thường gặp
          


          

            

              

                

                   Lỗi
                  thường gặp 1: Lỗi chia cho số 0 (ZeroDivisionError)
                

                

                  Trong lập trình, việc chia một số cho số 0 với toán tử
                  / hoặc // sẽ ngay lập tức làm chương
                  trình bị đứt luồng và báo ngoại lệ
                  ZeroDivisionError. Bạn luôn cần kiểm tra giá trị
                  mẫu số khác 0 trước khi thực hiện phép chia.
                

              


              

                

                   Lỗi thường
                  gặp 2: Lỗi sai số số thực (Floating-Point Precision Issues)
                

                

                  Do cách máy tính lưu trữ số thực dưới dạng nhị phân, phép tính
                  như 0.1 + 0.2 trong Python sẽ cho kết quả là
                  0.30000000000000004 thay vì 0.3 tròn
                  trịa. Khi xử lý giao dịch tiền tệ ngân hàng, bạn nên sử dụng
                  thư viện decimal thay vì số thực
                  float mặc định.
                

              


              

                

                   Lỗi
                  thường gặp 3: Khác biệt giữa chia số thực (/) và chia lấy phần
                  nguyên (//)
                

                

                  Toán tử / luôn luôn trả về kiểu số thực
                  float (ví dụ: 10 / 2 trả về
                  5.0), trong khi toán tử // làm tròn
                  xuống số nguyên nhỏ hơn gần nhất. Hãy chú ý chọn đúng loại
                  toán tử phù hợp với yêu cầu bài toán.
