Thực thi mã nguồn & quy trình vận hành Toán tử Số học và Toán tử Gán
Nguyên lý & lưu ý thực thi
Quy tắc vận hành chuẩn:

  • Sơ đồ luồng thực thi biểu thức toán học:
    • Dưới đây là thứ tự ưu tiên và luồng xử lý toán tử từ dữ liệu đầu vào đến khi ghi nhận kết quả cuối cùng.
```mermaid flowchart TD A["Đầu vào: Giá bán, Số lượng, Voucher, Sức chứa thùng"] --> B["Ưu tiên 1: Phép lũy thừa (**)"] B --> C["Ưu tiên 2: Phép nhân, chia, chia nguyên, chia dư (*, /, //, %)"] C --> D["Ưu tiên 3: Phép cộng, trừ (+, -)"] D --> E["Ưu tiên 4: Toán tử gán gộp (=, +=, -=, *=, /=)"] E --> F["Đầu ra: Kết quả số dư, số thùng và tổng tiền chính xác"] ```
  • Bảng tra cứu chi tiết các Toán tử số học:
| Toán tử | Tên gọi | Ví dụ mẫu | Kết quả | Mô tả hoạt động | | :--- | :--- | :--- | :--- | :--- | | `+` | Phép cộng | `150 + 50` | `200` | Cộng hai giá trị số | | `-` | Phép trừ | `200 - 30` | `170` | Trừ giá trị bên phải khỏi giá trị bên trái | | `*` | Phép nhân | `50 * 3` | `150` | Nhân hai giá trị số | | `/` | Phép chia | `10 / 4` | `2.5` | Phép chia float, **luôn trả về kiểu float** | | `//` | Phép chia nguyên | `10 // 4` | `2` | Chia lấy phần nguyên, làm tròn xuống (floor division) | | `%` | Phép chia dư | `10 % 4` | `2` | Chia lấy phần dư (Modulus) | | `**` | Phép lũy thừa | `2 ** 3` | `8` | Tính lũy thừa (2 mũ 3) |
  • Bảng tra cứu các Toán tử gán gộp (Augmented Assignment):
| Toán tử gán | Viết đầy đủ tương đương | Ý nghĩa ứng dụng | | :--- | :--- | :--- | | `x += 5` | `x = x + 5` | Cộng dồn 5 đơn vị vào biến `x` | | `x -= 3` | `x = x - 3` | Giảm 3 đơn vị khỏi biến `x` | | `x *= 2` | `x = x * 2` | Gấp đôi giá trị hiện tại của biến `x` | | `x /= 4` | `x = x / 4` | Chia giá trị của `x` cho 4 (kết quả thành `float`) | Lưu ý: Toán tử chia / luôn chuyển đổi kết quả thành kiểu dữ liệu float bất kể phép chia có chia hết hay không.", "solution_title": "Hướng Dẫn Thực Hành: Xây Dựng Biểu Thức Tính Toán Và Tối Ưu Mã Nguồn

Phòng tránh sự cố thực tế:

  • Tóm tắt bài học:
    • Python hỗ trợ 7 toán tử số học cơ bản: +, -, *, /, //, %, **.
    • Phép chia thực / luôn trả về kiểu số thực float. Phép chia nguyên // trả về phần nguyên và phép chia dư % trả về phần dư.
    • Các toán tử gán gộp (+=, -=, *=, /=) giúp mã nguồn ngắn gọn hơn so với cách gán lại thông thường.
  • Bài tập tự kiểm tra đánh giá (Self-Test):
  1. Câu 1 (Kịch bản đóng gói): Trong kho hàng có 23 chiếc máy tính cần đóng vào các hộp, mỗi hộp chứa tối đa 4 máy. Đoạn mã nào dưới đây tính chính xác số hộp đầy và số máy tính còn thừa chưa đóng hộp?
    • A. boxes = 23 / 4 và leftover = 23 % 4
    • B. boxes = 23 // 4 và leftover = 23 % 4
    • C. boxes = 23 ** 4 và leftover = 23 // 4
    • D. boxes = 23 % 4 và leftover = 23 // 4
  2. Câu 2 (Theo dõi biến): Cho đoạn mã Python sau: 
    balance = 1000 balance += 500 balance *= 0.9
    Giá trị và kiểu dữ liệu cuối cùng của biến balance là gì?
    • A. 1350 (kiểu int)
    • B. 1350.0 (kiểu float)
    • C. 1400.0 (kiểu float)
    • D. 1450 (kiểu int)
  3. Câu 3 (Bắt lỗi runtime): Biểu thức Python nào sau đây khi thực thi sẽ gây ra lỗi ZeroDivisionError?
    • A. result = 0 // 10
    • B. result = 10 % 3
    • C. result = 100 // (5 - 5)
    • D. result = 5 ** 0
Đáp án và giải thích chi tiết
  • Câu 1: Chọn B. Phép chia nguyên 23 // 4 cho kết quả 5 (hộp đầy), phép chia dư 23 % 4 cho kết quả dư 3 (máy tính lẻ).
  • Câu 2: Chọn B. Ban đầu balance = 1000. Sau += 500 biến thành 1500. Khi thực hiện *= 0.9 (nhân với float), kết quả biến đổi thành kiểu float: 1500 * 0.9 = 1350.0.
  • Câu 3: Chọn C. Biểu thức (5 - 5) bằng 0, do đó 100 // 0 vi phạm quy tắc toán học gây ra lỗi ZeroDivisionError. Các trường hợp 0 // 10 trả về 0, 5 ** 0 trả về 1 hoàn toàn hợp lệ.
