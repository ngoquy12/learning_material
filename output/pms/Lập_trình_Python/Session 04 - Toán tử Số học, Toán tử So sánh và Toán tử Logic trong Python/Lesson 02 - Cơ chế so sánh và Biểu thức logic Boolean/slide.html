Phòng tránh sự cố thực tế:

- **Tóm tắt nội dung trọng tâm**: - Toán tử so sánh (`==`, `!=`, `>`, `<`, `>=`, `<=`) dùng để đối chiếu hai giá trị và luôn trả về kết quả kiểu Boolean. - Kiểu Boolean chỉ gồm hai giá trị: `True` (Đúng) và `False` (Sai), bắt buộc viết hoa chữ cái đầu. - Cần đảm bảo hai giá trị so sánh phải tương thích về kiểu dữ liệu để tránh kết quả sai lệch hoặc lỗi chương trình. - **Bài tập tự đánh giá (Self-Test Assessment)**: **Câu 1 (Tình huống thực tế)**: Cho đoạn mã Python kiểm tra hạn mức tồn kho của một sản phẩm trong hệ thống quản lý: ```python current_stock = 25 min_threshold = 25 result = current_stock > min_threshold ``` Giá trị của biến `result` thu được là gì và vì sao? - A. `True`, vì số lượng tồn kho đạt mức 25. - B. `False`, vì toán tử `>` không tính trường hợp hai vế bằng nhau. - C. `SyntaxError`, vì không được phép so sánh hai biến có giá trị giống nhau. - D. `None`, vì phép so sánh không hợp lệ. *Đáp án đúng*: **B**. Lý do: Phép so sánh `25 > 25` trả về `False` vì toán tử `>` yêu cầu vế trái phải lớn hơn hẳn vế phải. Để tính cả trường hợp bằng nhau, lập trình viên phải dùng toán tử `>=`. **Câu 2 (Tình huống xác thực kiểu dữ liệu)**: Xét đoạn mã kiểm tra mã định danh người dùng sau: ```python input_code = "100" target_code = 100 is_matched = (input_code == target_code) ``` Kết quả hiển thị của biến `is_matched` khi in ra màn hình là gì? - A. `True`, vì giá trị biểu diễn dạng chữ số đều là 100. - B. `TypeError`, vì Python cấm hoàn toàn phép so sánh giữa chuỗi và số. - C. `False`, vì hai biến thuộc hai kiểu dữ liệu khác nhau (`str` và `int`). - D. `SyntaxError`, vì thiếu thao tác ép kiểu trước khi so sánh. *Đáp án đúng*: **C**. Lý do: Trong Python, phép so sánh bằng `==` giữa kiểu chuỗi `"100"` và kiểu số nguyên `100` không bị bật lỗi chương trình nhưng trả về `False` do khác biệt về kiểu dữ liệu. **Câu 3 (Tình huống phát hiện lỗi cú pháp)**: Một lập trình viên viết câu lệnh kiểm tra xem điểm số `score` có đạt mức tối đa 100 hay không bằng dòng mã: `is_max = (score = 100)`. Phát biểu nào sau đây phản ánh đúng kết quả thực thi? - A. Biến `is_max` nhận giá trị `True` nếu `score` bằng 100. - B. Python báo lỗi cú pháp (`SyntaxError`) vì dùng dấu gán `=` thay vì toán tử so sánh `==`. - C. Biến `is_max` nhận giá trị số nguyên là `100`. - D. Biến `is_max` nhận giá trị `False` do chưa khởi tạo biến `score`. *Đáp án đúng*: **B**. Lý do: Trong Python, dấu `=` đại diện cho phép gán giá trị, không thể đặt bên trong biểu thức so sánh. Để kiểm tra sự bằng nhau, bắt buộc phải dùng toán tử `==`.
