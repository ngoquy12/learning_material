Toán tử Số học & Thứ tự ưu tiên

Hiểu sâu cách thức Python giải quyết các biểu thức toán học và sự khác biệt giữa các phép chia.

Thứ tự ưu tiên toán tử

  • Ngoặc đơn `()`: Mức ưu tiên cao nhất, tính toán trước.
  • Phép lũy thừa `**`: Được tính tiếp theo sau dấu ngoặc.
  • Nhân, chia, chia nguyên, chia dư (`*`, `/`, `//`, `%`): Cùng mức ưu tiên, thực hiện từ trái qua phải.
  • Phép cộng và trừ (`+`, `-`): Mức ưu tiên thấp nhất, thực hiện sau cùng.

Phân biệt 3 phép chia

  • / Chia thực: Luôn luôn trả về kiểu float (Ví dụ: `10 / 2 = 5.0`).
  • // Chia lấy nguyên: Làm tròn xuống số nguyên gần nhất (`int`).
  • % Chia lấy dư: Tìm số dư còn lại của phép chia.

Bộ mô phỏng tính toán số học

Python Script
x = 15
y = 4
result = x + y * 2
print(result, type(result))

Toán tử So sánh & Bản chất Đối chiếu Kiểu

So sánh bằng `==` giữa các kiểu dữ liệu khác nhau và lỗi so sánh không đồng nhất kiểu.

Bản chất của phép so sánh ==

  • Không tự động ép kiểu: Python so sánh giá trị và kiểm tra loại bộ nhớ. Khác kiểu (ví dụ: `18 == "18"`) luôn cho ra False.
  • So sánh số nguyên và số thực: Cho phép đối chiếu bình đẳng (ví dụ: `5 == 5.0` là True).

Phân biệt phép gán (=) và so sánh (==)

- Dấu = dùng để GÁN giá trị vào biến số.
- Dấu == dùng để SO SÁNH xem hai vế có bằng nhau không, trả về kiểu Boolean.

Bộ đối chiếu so sánh động

Python Script
val_a = 18 # int
val_b = "18" # str
check = val_a == val_b
print(check)
Kết quả đánh giá False

Không cùng kiểu dữ liệu (int và str), Python trả về False mà không ép kiểu.

Toán tử Logic & Cơ chế Đánh giá Ngắn mạch

Trực quan hóa hoạt động của `and`, `or`, `not` và cách Python bỏ qua biểu thức dư thừa.

Đánh giá ngắn mạch là gì?

  • Phép `and` (Ngắn mạch khi gặp False): Nếu biểu thức bên trái là `False`, Python kết luận ngay kết quả là `False` mà không bao giờ tính biểu thức bên phải.
  • Phép `or` (Ngắn mạch khi gặp True): Nếu biểu thức bên trái là `True`, Python kết luận ngay kết quả là `True` mà không bao giờ tính biểu thức bên phải.
  • Lợi ích: Tăng tốc độ thực thi và tránh được các lỗi run-time (Ví dụ: kiểm tra mẫu số khác 0 trước khi chia).
