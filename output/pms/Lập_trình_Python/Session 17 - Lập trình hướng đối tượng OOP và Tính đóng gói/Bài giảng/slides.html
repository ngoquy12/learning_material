Lesson 02

Giải mã Tham chiếu `self`

`self` là gì trong Python?

self đại diện cho chính đối tượng hiện tại đang thực thi phương thức.

1. Tham số đầu tiên bắt buộc

Mọi phương thức của đối tượng (Instance Method) đều phải nhận self làm tham số đầu tiên.

2. Cơ chế truyền ngầm định

Khi bạn gọi obj.method(), Python tự động truyền obj vào vị trí tham số self.

class Person:
    def __init__(self, name: str):
        # self.name là thuộc tính của đối tượng
        # name là tham số truyền vào hàm
        self.name = name

    def say_hello(self):
        print(f"Xin chào, tôi là {self.name}")

p1 = Person("Alice")

# Hai cách gọi sau đây hoàn toàn tương đương:
p1.say_hello()         # Cách viết thông thường
Person.say_hello(p1)   # Bản chất vận hành của Python

Lesson 03

Phương thức đối tượng (Instance Method)

Định nghĩa

Là các hàm được định nghĩa bên trong Class để đại diện cho hành vi (Behavior) của đối tượng.

Đặc điểm chính

  • Luôn có tham số self ở vị trí đầu tiên.
  • Có thể đọc và sửa đổi các thuộc tính qua self. 
class Circle:
    def __init__(self, radius: float):
        self.radius = radius

    # Instance Method tính diện tích
    def get_area( me ) -> float:
        return 3.14159 * (self.radius ** 2)

    # Instance Method cập nhật bán kính
    def set_radius(self, new_radius: float):
        if new_radius > 0:
            self.radius = new_radius

c = Circle(5.0)
print(c.get_area())  # 78.53975

c.set_radius(10.0)
print(c.get_area())  # 314.159

Minh họa Code: Class Attribute vs Instance Attribute

class Employee:
    # Class Attribute: Dùng chung toàn bộ công ty
    company_name: str = "Rikkei Academy"
    employee_count: int = 0

    def __init__(self, name: str, salary: float):
        # Instance Attributes: Riêng biệt cho từng nhân viên
        self.name = name
        self.salary = salary
        
        # Cập nhật thuộc tính Class thông qua tên Lớp
        Employee.employee_count += 1

emp1 = Employee("Nguyễn Văn A", 1500.0)
emp2 = Employee("Trần Thị B", 2000.0)

print(emp1.company_name)   # "Rikkei Academy"
print(Employee.employee_count) # Output: 2

Tính đóng gói (Encapsulation) là gì?

Định nghĩa

Tính đóng gói là kỹ thuật che giấu dữ liệu nội bộ bên trong đối tượng và chỉ cung cấp các giao diện public hợp lệ để tương tác với dữ liệu đó từ bên ngoài.

Bảo vệ dữ liệu

Ngăn chặn việc sửa đổi trực tiếp dữ liệu trái phép hoặc gán giá trị sai logic.

Che giấu chi tiết

Ẩn đi sự phức tạp của thuật toán xử lý nội bộ khỏi bên ngoài.

Capsule Principle

Dữ liệu (Data) + Hành vi (Methods) được gói gọn thành một viên nang bảo vệ.

Access Modifiers trong Python

Public

Tự do truy cập

Không có dấu gạch dưới làm tiền tố.

self.name = "Alice"
Protected (_)

Quy ước nội bộ

Có 1 dấu gạch dưới _ làm tiền tố. Gợi ý chỉ dùng trong Lớp & Lớp con.

self._salary = 1000
Private (__)

Bảo mật tuyệt đối

Có 2 dấu gạch dưới __ làm tiền tố. Kích hoạt Name Mangling.

self.__pin_code = 1234

Lesson 04

Cơ chế Name Mangling cho Private Attribute

Cách Python xử lý Private

Khi biến bắt đầu bằng __, Python sẽ tự động đổi tên biến thành dạng:

_ClassName__attributeName

Điều này ngăn chặn việc ngẫu nhiên ghi đè hoặc truy cập trực tiếp từ bên ngoài instance. 

class BankAccount:
    def __init__(self, balance: float):
        self.__balance = balance  # Private attribute

acc = BankAccount(1000.0)

# Truy cập trực tiếp sẽ báo lỗi AttributeError:
# print(acc.__balance) 

# Bản chất tên biến đã bị đổi thành (Name Mangling):
print(acc._BankAccount__balance)  # Output: 1000.0 
# (Lưu ý: Không nên truy cập theo cách này trong production code)

Lesson 04

Getter & Setter với Decorator `@property`

Phong cách Pythonic

Thay vì viết get_balance() hay set_balance() kiểu Java, Python sử dụng decorator @property để truy cập phương thức như một thuộc tính thông thường.

Lợi ích: Cho phép kiểm tra tính hợp lệ (Validation) của dữ liệu trước khi gán giá trị mới. 
class Product:
    def __init__(self, name: str, price: float):
        self.name = name
        self.__price = price  # Private

    @property
    def price( me ) -> float:  # Getter
        return self.__price

    @price.setter
    def price(self, new_price: float):  # Setter
        if new_price < 0:
            raise ValueError("Giá sản phẩm không thể âm!")
        self.__price = new_price

p = Product("Laptop", 1200.0)
p.price = 1500.0  # Tự động gọi @price.setter
print(p.price)    # Tự động gọi @property Getter (1500.0)

Ứng dụng: Quản lý Tài khoản Ngân hàng

class BankAccount:
    def __init__(self, owner: str, initial_balance: float):
        self.owner = owner
        self.__balance = initial_balance  # Đóng gói dữ liệu số dư

    @property
    def balance(self) -> float:
        return self.__balance

    def deposit(self, amount: float):
        if amount > 0:
            self.__balance += amount
            print(f"Nạp +{amount:,.0f} VNĐ. Số dư hiện tại: {self.__balance:,.0f} VNĐ")

    def withdraw(self, amount: float):
        if 0 < amount <= self.__balance:
            self.__balance -= amount
            print(f"Rút -{amount:,.0f} VNĐ. Số dư còn lại: {self.__balance:,.0f} VNĐ")
        else:
            print("Giao dịch thất bại: Số dư không đủ hoặc số tiền không hợp lệ!")

# Khởi tạo sử dụng
account = BankAccount("Nguyễn Văn A", 5000000)
account.deposit(2000000)   # Nạp thành công
account.withdraw(8000000)  # Cảnh báo thất bại
