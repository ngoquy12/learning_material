Kiểm tra kiểu dữ liệu và Ép kiểu (Type Casting)

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Chuyển sang Slide 5: Ép kiểu dữ liệu Thực thi hàm type() và các hàm ép kiểu int(), float(), str() trong Terminal 
# Kiểm tra kiểu dữ liệu
num_str = "100"
print(type(num_str))  # Output: 

# Ép kiểu tường minh (Explicit Casting)
num_int = int(num_str)
print(num_int + 50)   # Output: 150

# Ép kiểu ngầm định (Implicit Casting)
x = 10 + 2.5          # x tự động thành float: 12.5
