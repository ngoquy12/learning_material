Khai báo biến, quy tắc đặt tên và các kiểu dữ liệu cơ sở

1. Tại sao cần khai báo biến đúng cách và tuân thủ chuẩn đặt tên PEP 8?

Trong các dự án phần mềm doanh nghiệp, mã nguồn không chỉ được viết cho máy tính thực thi mà còn để các kỹ sư trong team cùng đọc, bảo trì và phát triển tiếp. Xét ví dụ thực tế tại một hệ thống quản lý kho và bán hàng thương mại điện tử: khi lập trình viên cũ viết mã nguồn sử dụng các tên biến viết tắt tùy tiện, không theo chuẩn mực và không nắm rõ kiểu dữ liệu, hệ thống sẽ nhanh chóng rơi vào tình trạng hỗn loạn.

Những cách làm cũ thiếu chuẩn hóa thường gặp phải các điểm đau (pain points) nghiêm trọng sau:

  • Tên biến mơ hồ, thiếu ngữ cảnh: Đặt tên biến ngắn ngủi như a, x1, temp_val khiến người đọc không thể hiểu biến đó đại diện cho số lượng hàng trong kho, đơn giá hay trạng thái tài khoản.
  • Phong cách đặt tên không thống nhất: Trộn lẫn giữa các quy tắc khác nhau như CamelCase (totalPrice), PascalCase (UserAge) và gạch nối bất hợp lệ (user-status), làm vi phạm quy chuẩn cộng đồng Python (PEP 8).
  • Trôi kiểu dữ liệu ngầm định (Implicit Type Confusion): Nhầm lẫn giữa số nguyên (int), số thực (float), chuỗi ký tự (str) và kiểu luận lý (bool). Ví dụ: lưu số tiền dưới dạng chuỗi "150000" dẫn đến việc tính toán sai lệch hoặc lỗi chương trình đột ngột.

Giải pháp Pythonic: Áp dụng chuẩn đặt tên snake_case theo tài liệu hướng dẫn PEP 8 và xác định rõ kiểu dữ liệu ngay khi khai báo biến giúp mã nguồn trở nên tự giải thích (self-documenting), giảm thiểu 90% lỗi logic liên quan đến dữ liệu.

2. Cú pháp khai báo biến, quy tắc PEP 8 và các kiểu dữ liệu cơ sở trong Python

2.1. Cú pháp khai báo biến và cơ chế lưu trữ bộ nhớ trong Python

Trong Python, biến (variable) là tên gọi đại diện cho một vùng nhớ lưu trữ giá trị. Khác với các ngôn ngữ biên dịch như C/C++ hay Java, Python sử dụng cơ chế gán động (Dynamic Typing). Người lập trình không cần khai báo từ khóa kiểu dữ liệu trước tên biến, Python sẽ tự động xác định kiểu dựa trên giá trị được gán.

Cú pháp mẫu Python 
variable_name = value
Cú pháp mẫu Python 
# Declare integer and float variables
item_count = 10
item_price = 29.99
  • variable_name: Tên của biến, đóng vai trò là nhãn tham chiếu đến đối tượng trong bộ nhớ.
  • =: Toán tử gán (assignment operator), đưa giá trị từ vế phải vào địa chỉ ô nhớ mà tên biến ở vế trái trỏ tới.
  • value: Giá trị cụ thể thuộc một kiểu dữ liệu xác định (int, float, str, bool).

2.2. Quy tắc đặt tên biến snake_case theo chuẩn PEP 8

PEP 8 (Python Enhancement Proposal 8) là quy chuẩn viết mã nguồn chính thức của ngôn ngữ Python. Theo PEP 8, tên biến phải sử dụng phong cách snake_case: viết thường toàn bộ các chữ cái và nối giữa các từ bằng dấu gạch dưới _.

Cú pháp mẫu Python 
snake_case_variable = value
Cú pháp mẫu Python 
# Standard PEP 8 variable naming examples
total_user_count = 500
is_order_completed = True
  • snake_case_variable: Tên biến kết hợp nhiều từ bằng dấu gạch dưới, giúp tên biến danh từ hóa rõ nghĩa.
  • Ký tự đầu tiên phải là chữ cái (a-z, A-Z) hoặc dấu gạch dưới (_). Tuyệt đối không bắt đầu bằng chữ số.
  • Tên biến chỉ chứa các chữ cái, chữ số (0-9) và dấu gạch dưới. Không chứa ký tự đặc biệt như @, $, % hay dấu gạch nối -.
  • Không trùng với các từ khóa hệ thống (Reserved Keywords) của Python như class, import, for, if, return.

2.3. Các kiểu dữ liệu cơ sở trong Python (Basic Data Types)

Python hỗ trợ 4 kiểu dữ liệu cơ sở cơ bản nhất để biểu diễn thông tin trong ứng dụng:

Cú pháp mẫu Python 
# Demonstration of basic Python data types
age = 30                  # int
temperature = 36.6        # float
user_name = "Alice"       # str
is_verified = True        # bool
  • int (Integer): Kiểu số nguyên âm hoặc dương, không chứa phần thập phân (ví dụ: 10, -5, 0).
  • float (Floating-point number): Kiểu số thực chứa dấu chấm thập phân (ví dụ: 3.14, -0.5, 2.0).
  • str (String): Kiểu chuỗi ký tự được đặt trong cặp dấu ngoặc đơn '...' hoặc ngoặc kép "..." (ví dụ: "Hello World").
  • bool (Boolean): Kiểu luận lý chỉ nhận 1 trong 2 giá trị: True (Đúng) hoặc False (Sai). Lưu ý viết hoa chữ cái đầu.

2.4. Kiểm tra kiểu dữ liệu với hàm type()

Để xác định chính xác kiểu dữ liệu của một biến đang lưu trữ trong quá trình thực thi, Python cung cấp hàm tích hợp type().

Cú pháp mẫu Python 
type(object)
Cú pháp mẫu Python 
# Inspecting variable data types
data_value = 100
data_type = type(data_value)
  • object: Biến hoặc giá trị cần kiểm tra kiểu dữ liệu.
  • data_type: Kết quả trả về dưới dạng lớp kiểu dữ liệu (ví dụ: <class 'int'>).

4. Tổng kết và các lưu ý

          

            
 4.1. Các lỗi phổ biến khi đặt tên biến và vi phạm PEP 8
  • Đặt tên bắt đầu bằng chữ số: Khai báo như 1st_user = "John" sẽ gây ra lỗi cú pháp SyntaxError: invalid syntax.
  • Sử dụng từ khóa bảo lưu (Reserved Keywords): Đặt tên biến trùng với từ khóa hệ thống như class = "Math" hoặc import = 10 bị cấm tuyệt đối.
  • Dùng ký tự gạch nối thay cho gạch dưới: Khai báo user-age = 20 khiến Python hiểu nhầm là phép trừ giữa hai biến user và age.
 4.2. Cạm bẫy trôi kiểu dữ liệu ngầm định và nhầm lẫn Boolean
  • Nối chuỗi số thay vì cộng số: Thực hiện toán tử cộng giữa hai chuỗi chứa số "10" + "20" trả về "1020" (kiểu chuỗi), không phải 30 (kiểu số nguyên).
  • Viết thường giá trị Boolean: Viết is_active = true hoặc is_active = false dẫn đến lỗi NameError vì Python phân biệt chữ hoa chữ thường và bắt buộc ghi là True hay False.
