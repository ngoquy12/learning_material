Bẫy lỗi: Ghép chuỗi và Ép kiểu dữ liệu

Chỉ dẫn thao tác studio
Cam 1 (Close-up)
Cảnh báo bẫy ghép chuỗi khi cộng 2 string Demo giải pháp Ép kiểu rõ ràng (Explicit Type Casting) 
# LỖI: Quên ép kiểu -> Phép + bị hiểu nhầm thành ghép chuỗi
quantity = input("Số lượng mã CK: ") # "10"
price = input("Đơn giá cổ phiếu: ")     # "50.5"
total = quantity + price             # "1050.5" (SAI!)

# CHUẨN: Ép kiểu rõ ràng (Explicit Casting)
quantity = int(input("Số lượng mã CK: ")) # Ép sang int
price = float(input("Đơn giá cổ phiếu: "))   # Ép sang float
total = quantity * price                     # 505.0 (ĐÚNG!)
Lời thoại Teleprompter / : ngắt nhịp ngắn • // : ngắt hơi nghỉ

Đây là một bẫy lỗi vô cùng nguy hiểm trong các ứng dụng thực tế! // Nếu quên ép kiểu, / phép cộng giữa hai chuỗi "10" và "50.5" sẽ gây ra kết quả ghép chuỗi là "1050.5" thay vì phép toán số học. // Giải pháp là áp dụng Explicit Type Casting: / bọc các hàm int() hoặc float() trực tiếp bên ngoài hàm input() để chuyển đổi kiểu dữ liệu chính xác.
