# Ép kiểu ngầm định (Implicit)
x = 10     # int
y = 2.5    # float
z = x + y  # float (12.5)

# Ép kiểu tường minh (Explicit)
age = int(input("Nhập tuổi: "))
height = float(input("Nhập chiều cao (m): "))
is_student = bool(int(input("Là sinh viên (1: Có, 0: Không): ")))

Trong Python, chuyển đổi kiểu dữ liệu bao gồm hai dạng: ép kiểu ngầm định và ép kiểu tường minh. // Ép kiểu ngầm định diễn ra tự động khi Python tự thực hiện nâng cấp kiểu dữ liệu, ví dụ cộng số nguyên int với số thực float sẽ cho ra kết quả kiểu float. // Ngược lại, ép kiểu tường minh là khi lập trình viên chủ động dùng các hàm như int(), float(), str(), hay bool() để biến đổi dữ liệu. / Đây là kỹ thuật vô cùng phổ biến khi xử lý kết quả nhận từ input().
