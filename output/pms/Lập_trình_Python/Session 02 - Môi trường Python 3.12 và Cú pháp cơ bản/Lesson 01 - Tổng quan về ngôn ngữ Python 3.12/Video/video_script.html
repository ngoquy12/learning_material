QUẢN LÝ THAM CHIẾU ĐỐI TƯỢNG (REFERENCE COUNTING)

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Chuyển sang Slide 2: Quản lý tham chiếu đối tượng Minh họa code Python đếm số lượng tham chiếu với sys.getrefcount() 
import sys

# Khởi tạo đối tượng số nguyên trong Heap
x = [1, 2, 3] 

# y tham chiếu cùng đối tượng với x
y = x 

# Đếm số lượng tham chiếu hiện tại
print(sys.getrefcount(x)) 
# Output: 3 (x, y và tham chiếu tạm thời từ getrefcount)

# Xóa tham chiếu y
del y
print(sys.getrefcount(x))
# Output: 2
Lời thoại Teleprompter / : ngắt nhịp ngắn • // : ngắt hơi nghỉ

Tiếp theo / chúng ta sẽ đến với cơ chế Quản lý tham chiếu đối tượng (Reference Counting) trong bộ nhớ. // Trong Python / mọi thứ đều là Đối tượng (Object). Biến không trực tiếp chứa giá trị mà chỉ lưu địa chỉ tham chiếu trỏ đến đối tượng. // CPython sẽ tự động tăng số lượng tham chiếu khi có biến mới trỏ tới / và giảm đi khi biến hết phạm vi sử dụng. // Khi Reference Count bằng 0 / hệ thống sẽ kích hoạt Tự động thu gom rác (Garbage Collection) để giải phóng vùng nhớ / tránh hiện tượng Memory Leak. // Quan sát đoạn code minh họa / hàm sys.getrefcount(x) giúp chúng ta kiểm tra chính xác số lượng tham chiếu hiện tại của đối tượng.

Chỉ dẫn thao tác studio

Chuyển sang Slide 4: Quy trình thiết lập .venv chuẩn Enterprise Hiển thị các câu lệnh Terminal khởi tạo và kích hoạt môi trường ảo 
# Bước 1: Khởi tạo môi trường ảo biệt lập với Python 3.12 SDK
python3.12 -m venv .venv

# Bước 2: Kích hoạt môi trường ảo (Linux / macOS)
source .venv/bin/activate

# (Hoặc kích hoạt trên Windows PowerShell: .venv\Scripts\Activate.ps1)

# Bước 3: Nâng cấp pip và cài đặt gói phụ thuộc từ requirements.txt
pip install --upgrade pip
pip install -r requirements.txt

# Bước 4: Kiểm tra đường dẫn thực thi đã được cách ly thành công
which python
# Output chuẩn: /Users/developer/enterprise_project/.venv/bin/python
