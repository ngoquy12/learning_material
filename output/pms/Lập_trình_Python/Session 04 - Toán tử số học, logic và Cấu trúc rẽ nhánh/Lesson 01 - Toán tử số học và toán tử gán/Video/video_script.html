Toán tử gán và toán tử gán kết hợp

Chỉ dẫn thao tác studio
Cam 1 (Close-up)
Hiển thị sơ đồ Toán tử gán kết hợp So sánh x = x + 5 và x += 5 
x = 10

# Toán tử gán kết hợp
x += 5   # Tương đương: x = x + 5  -> x = 15
x -= 3   # Tương đương: x = x - 3  -> x = 12
x *= 2   # Tương đương: x = x * 2  -> x = 24
x /= 4   # Tương đương: x = x / 4  -> x = 6.0

print("Giá trị cuối cùng của x:", x)
