2.1. Cú pháp và giải thích Toán tử số học (Arithmetic Operators)

Toán tử số học thực hiện các phép tính đại số cơ bản và nâng cao trong Python.

Cú pháp toán tử số học trong Python
result = operand_a operator operand_b

Chi tiết thành phần cú pháp:

  • operator: Bao gồm + (Cộng), - (Trừ), * (Nhân), / (Chia số thực), // (Chia nguyên), % (Chia lấy dư), ** (Lũy thừa).
Yêu cầu bài toán thực hành (Tính tổng tiền hàng ShopeeFood):

Tính tổng chi phí 3 phần cơm tấm giá 45.000 VNĐ, cộng 20.000 VNĐ phí ship và trừ 15.000 VNĐ voucher.

unit_price = 45000
quantity = 3
shipping_fee = 20000
discount_voucher = 15000

subtotal = unit_price * quantity
total_payment = subtotal + shipping_fee - discount_voucher

print('Tiền hàng:', subtotal, 'VNĐ')
print('Tổng thanh toán:', total_payment, 'VNĐ')

            3. Các ví dụ ứng dụng thực tiễn trong hệ thống ShopeeFood
          


          

            

3.1. Tính tổng chi phí đơn hàng ShopeeFood bao gồm phụ phí và chiết khấu


Tính toán chi tiết giá trị thanh toán cho đơn hàng gồm trà sữa và phí vận chuyển.



  
 Yêu cầu bài toán thực hành (Bài toán 3.1 - Tính tiền đơn trà sữa):

  
Tính tổng tiền 2 ly trà sữa giá 30.000 VNĐ, giảm 10% và cộng 15.000 VNĐ phí ship.





  

    

      
      
      
    

    
item_price = 30000
item_qty = 2
shipping_fee = 15000
discount_percent = 0.10

subtotal = item_price * item_qty
discount_amount = subtotal * discount_percent
final_amount = (subtotal - discount_amount) + shipping_fee

print('Tiền hàng gốc:', subtotal, 'VNĐ')
print('Số tiền giảm:', discount_amount, 'VNĐ')
print('Thành tiền:', final_amount, 'VNĐ')

  

  

    

       KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
    

    

  





3.2. Cập nhật tích lũy điểm thưởng và số dư ví bằng toán tử gán


Khấu trừ tiền hàng và tích lũy điểm thưởng ShopeePay.



  
 Yêu cầu bài toán thực hành (Bài toán 3.2 - Tích lũy điểm thưởng 5%):

  
Trừ 165.000 VNĐ tiền đơn hàng khỏi ví và tích dồn 5% giá trị đơn thành điểm thưởng.





  

    

      
      
      
    

    
wallet_balance = 350000
user_points = 80
bill_total = 165000

wallet_balance -= bill_total
earned_points = int(bill_total * 0.05)
user_points += earned_points

print('Ví còn lại:', wallet_balance, 'VNĐ')
print('Điểm mới:', user_points)

3.3. Chia tiền hóa đơn nhóm và tính số tiền lẻ dư


Sử dụng phép chia nguyên // và chia dư % để chia tiền hóa đơn nhóm.



  
 Yêu cầu bài toán thực hành (Bài toán 3.3 - Phân chia hóa đơn ăn nhóm):

  
Chia đều hóa đơn 355.000 VNĐ cho nhóm 4 người và tính tiền dư lẻ còn lại.





  

    

      
      
      
    

    
group_bill = 355000
num_people = 4

share_per_person = group_bill // num_people
remaining_change = group_bill % num_people

print('Mỗi người đóng:', share_per_person, 'VNĐ')
print('Tiền dư lẻ:', remaining_change, 'VNĐ')

            4. Tổng kết bài học & Các lỗi thường gặp
          


          

            


  

    
 Lỗi thường gặp 1: Lỗi chia cho số 0 (ZeroDivisionError)

    
Chia cho số 0 sẽ làm chương trình dừng và báo lỗi ZeroDivisionError.

  

  

    
 Lỗi thường gặp 2: Sai số số thực (Floating-Point Precision)

    
Phép tính 0.1 + 0.2 cho kết quả 0.30000000000000004 do cách máy tính lưu số thực.

  

  

    
 Lỗi thường gặp 3: Khác biệt giữa chia / và chia lấy phần nguyên //

    
Toán tử / luôn trả về số thực float, còn // cắt bỏ phần thập phân trả về int.
