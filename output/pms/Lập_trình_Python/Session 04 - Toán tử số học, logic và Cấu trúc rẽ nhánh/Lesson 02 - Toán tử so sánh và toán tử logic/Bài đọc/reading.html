2.1. Cú pháp và cơ chế hoạt động của Toán tử so sánh

Toán tử so sánh so sánh hai giá trị và luôn trả về kết quả kiểu Boolean (True hoặc False).

Yêu cầu bài toán thực hành (So sánh giá trị đơn hàng với ngưỡng Freeship 200k):

Kiểm tra đơn hàng giá trị 250.000 VNĐ có lớn hơn hoặc bằng ngưỡng 200.000 VNĐ hay không.

order_amount = 250000
is_eligible_freeship = order_amount >= 200000
print('Đơn hàng đạt chuẩn freeship:', is_eligible_freeship)

2.2. Cú pháp và cơ chế hoạt động của Toán tử logic (and, or, not)


Toán tử logic kết hợp hoặc đảo ngược các giá trị Boolean.




  
 Yêu cầu bài toán thực hành (Kết hợp điều kiện Freeship và Thành viên VIP):

  
Xác nhận Freeship nếu đơn từ 200.000 VNĐ VÀ người dùng là thành viên VIP.





  

    

      
      
      
    

    
order_amount = 250000
is_vip = True

is_approved = (order_amount >= 200000) and is_vip
print('Được phê duyệt ưu đãi freeship VIP:', is_approved)

3.1. Xác thực điều kiện miễn phí giao hàng ShopeeFood


Đánh giá cờ hiệu miễn phí giao hàng dựa trên tổng tiền và hạng thành viên.



  
 Yêu cầu bài toán thực hành (Bài toán 3.1 - Kiểm tra điều kiện Freeship):

  
Kiểm tra đơn hàng 250.000 VNĐ của thành viên VIP có được miễn phí giao hàng.





  

    

      
      
      
    

    
order_amount = 250000
is_vip_member = True
is_freeship = (order_amount >= 200000) and is_vip_member
print('Miễn phí giao hàng:', is_freeship)

3.2. Kiểm tra điều kiện áp dụng mã giảm giá Voucher


Đơn hàng được giảm giá nếu đạt từ 150.000 VNĐ trở lên VÀ có voucher hoặc là VIP.



  
 Yêu cầu bài toán thực hành (Bài toán 3.2 - Áp dụng Voucher 30k):

  
Kiểm tra đơn 180.000 VNĐ có voucher và là thành viên VIP.





  

    

      
      
      
    

    
order_val = 180000
has_voucher = True
is_vip = False

is_discounted = (order_val >= 150000) and (has_voucher or is_vip)
print('Được áp dụng giảm giá:', is_discounted)

3.3. Đánh giá ngắn mạch (Short-circuit Evaluation) tối ưu hiệu năng


Kiểm tra cờ hiệu vi phạm trước để kích hoạt cơ chế ngắn mạch dừng đánh giá sớm.



  
 Yêu cầu bài toán thực hành (Bài toán 3.3 - Ngắn mạch kiểm tra tài khoản bị khóa):

  
Kiểm tra tài khoản bị khóa (is_banned = True) dừng đánh giá biểu thức ngay lập tức.





  

    

      
      
      
    

    
is_banned = True
order_amount = 500000

is_valid = (not is_banned) and (order_amount >= 100000)
print('Đơn hàng được chấp nhận:', is_valid)

            4. Tổng kết bài học & Các lỗi thường gặp
          


          

            


  

    
 Lỗi thường gặp 1: Nhầm lẫn giữa toán tử gán = và so sánh bằng ==

    
Dấu = dùng để gán giá trị, dấu == mới dùng để so sánh bằng.

  

  

    
 Lỗi thường gặp 2: Sai độ ưu tiên giữa toán tử and và or

    
Toán tử and có độ ưu tiên cao hơn or. Hãy dùng cặp ngoặc () để nhóm điều kiện rõ ràng.

  

  

    
 Lỗi thường gặp 3: Quên sử dụng phép phủ định not

    
Viết if is_banned: sẽ bị ngược logic so với if not is_banned:.
