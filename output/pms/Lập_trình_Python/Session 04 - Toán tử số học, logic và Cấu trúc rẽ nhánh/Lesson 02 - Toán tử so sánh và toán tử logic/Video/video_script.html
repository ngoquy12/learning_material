Phân cảnh 03 02:15 - 03:45

Toán tử logic: and, or, not

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Hiển thị Slide 3: Các toán tử logic and, or, not Phân tích bảng chân trị và các ví dụ thực tế 
age = 25
has_license = True

# Toán tử and: Tất cả điều kiện phải đúng
can_drive = (age >= 18) and has_license  # True

# Toán tử or: Ít nhất một điều kiện đúng
is_student = False
is_discounted = is_student or (age < 30)  # True

# Toán tử not: Đảo ngược kết quả Boolean
print(not can_drive)  # False

Độ ưu tiên toán tử và Cơ chế Short-circuit

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Hiển thị Slide 4: Thứ tự ưu tiên và Short-circuit Evaluation Minh họa thứ tự thực thi: not -> and -> or 
# Thứ tự ưu tiên: not -> and -> or
result = True or False and not True  # True

# Short-circuit Evaluation (Đánh giá ngắn mạch)
x = 5
y = 0
# Do (y != 0) là False, Python dừng tính toán vế sau
is_valid = (y != 0) and (x / y > 2)  # False (Không xảy ra lỗi chia cho 0)
