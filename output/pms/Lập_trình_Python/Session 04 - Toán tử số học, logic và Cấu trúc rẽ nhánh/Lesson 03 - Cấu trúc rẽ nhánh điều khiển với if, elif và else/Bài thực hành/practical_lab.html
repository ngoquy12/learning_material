Bài thực hành: Cấu trúc rẽ nhánh trong Python

Bài thực hành: Xây dựng hệ thống tính tiền và khuyến mãi đơn hàng tự động (ShopeeFood)

Thực hành chỉnh sửa dữ liệu và chạy trực tiếp mã nguồn Python ngay trên trình duyệt.

1. Mục tiêu bài học

  • Vận dụng thành thạo cấu trúc rẽ nhánh if, if-else, và if-elif-else trong Python để giải quyết bài toán nghiệp vụ thực tế.
  • Đảm bảo tuân thủ 100% quy tắc thụt lề (Indentation 4 spaces) và đặt tên biến tiếng Anh snake_case chuẩn PEP 8.
  • Trực tiếp nhập/chỉnh sửa mã nguồn và thực thi kiểm thử trên trình duyệt (Pyodide WASM Engine).

2. Yêu cầu bài toán

Bối cảnh nghiệp vụ ShopeeFood:

Bạn được giao nhiệm vụ phát triển một mô-đun Python cho hệ thống xử lý hóa đơn thanh toán của ShopeeFood. Chương trình cần nhận các thông tin đơn hàng đầu vào và tự động tính toán tổng số tiền thanh toán cuối cùng dựa trên 3 quy tắc kinh doanh:

  1. Kiểm tra tính hợp lệ dữ liệu: Giá trị đơn hàng (order_amount) phải lớn hơn 0. Nếu order_amount <= 0, in thông báo lỗi dữ liệu không hợp lệ và dừng tính toán.
  2. Xác định mức giảm giá (if-elif-else):
    • Đơn hàng từ 300,000đ trở lên: Giảm thẳng 50,000đ (discount_amount = 50000).
    • Đơn hàng từ 150,000đ đến dưới 300,000đ: Giảm 20,000đ (discount_amount = 20000).
    • Đơn hàng dưới 150,000đ: Không giảm giá (discount_amount = 0).
  3. Xác định phí vận chuyển (if-else):
    • Miễn phí ship (shipping_fee = 0) nếu khách hàng là VIP (is_vip = True) HOẶC giá trị đơn hàng từ 200,000đ trở lên.
    • Ngược lại: Tính phí ship mặc định 15,000đ (shipping_fee = 15000).

3. Các bước thực hiện

  1. Khởi tạo biến đầu vào: Khai báo order_amount (giá trị đơn) và is_vip (trạng thái VIP).
  2. Kiểm tra dữ liệu hợp lệ: Dùng câu lệnh if order_amount <= 0: để ngăn chặn dữ liệu không hợp lệ.
  3. Phân loại mức giảm giá: Dùng chuỗi rẽ nhánh if-elif-else kiểm tra các mốc 300,000đ và 150,000đ.
  4. Tính phí vận chuyển: Dùng if-else kết hợp toán tử logic or kiểm tra is_vip or order_amount >= 200000.
  5. Tính tổng thanh toán & In hóa đơn: Tính total_payment = order_amount - discount_amount + shipping_fee và hiển thị hóa đơn.

4. Mã nguồn tham khảo & Thực thi trực tiếp 

# ==============================================================================
# HỆ THỐNG TÍNH TIỀN & KHUYẾN MÃI ĐƠN HÀNG SHOPEEFOOD
# ==============================================================================

# BƯỚC 1: Khởi tạo dữ liệu đơn hàng (Sinh viên hãy thử sửa đổi 2 giá trị này)
order_amount = 250000     # Giá trị đơn hàng (VNĐ)
is_vip = True             # Trạng thái khách hàng VIP (True / False)

# BƯỚC 2: Kiểm tra dữ liệu đầu vào hợp lệ
if order_amount <= 0:
    print("❌ LỖI: Giá trị đơn hàng không hợp lệ! Vui lòng nhập số lớn hơn 0.")
else:
    # BƯỚC 3: Phân loại mức giảm giá theo mốc đơn hàng
    if order_amount >= 300000:
        discount_amount = 50000
    elif order_amount >= 150000:
        discount_amount = 20000
    else:
        discount_amount = 0

    # BƯỚC 4: Tính phí vận chuyển (Miễn phí ship cho Khách VIP hoặc Đơn >= 200k)
    if is_vip or order_amount >= 200000:
        shipping_fee = 0
    else:
        shipping_fee = 15000

    # BƯỚC 5: Tính tổng thanh toán cuối cùng
    total_payment = order_amount - discount_amount + shipping_fee

    # HIỂN THỊ HÓA ĐƠN THANH TOÁN
    print("----------------------------------------")
    print("       HÓA ĐƠN THANH TOÁN SHOPEEFOOD    ")
    print("----------------------------------------")
    print(f"Giá gốc đơn hàng  : {order_amount:,.0f} VNĐ")
    print(f"Khách hàng VIP    : {'Có' if is_vip else 'Không'}")
    print(f"Mức giảm giá      : -{discount_amount:,.0f} VNĐ")
    print(f"Phí vận chuyển    : +{shipping_fee:,.0f} VNĐ")
    print("----------------------------------------")
    print(f"TỔNG THANH TOÁN   : {total_payment:,.0f} VNĐ")
    print("----------------------------------------")
