Cấu trúc rẽ nhánh điều khiển với if, elif và else

1. Thách thức khi xử lý logic phân loại đơn hàng không có rẽ nhánh điều khiển

Trong hệ thống xử lý đơn hàng của một sàn thương mại điện tử như Shopee hay Lazada, việc tự động tính toán tỷ lệ chiết khấu và ưu đãi vận chuyển dựa trên giá trị đơn hàng là nhiệm vụ cốt lõi. Nếu chương trình máy tính chỉ chạy các câu lệnh tuần tự từ trên xuống dưới mà không có khả năng kiểm tra điều kiện để chọn nhánh xử lý phù hợp, tất cả các mức giảm giá sẽ bị áp dụng dồn dập vào cùng một đơn hàng.

Giả sử hệ thống quy định: Đơn hàng từ 1.000.000 VNĐ được giảm 15%, đơn hàng từ 500.000 VNĐ được giảm 10%. Nếu mã nguồn viết theo lối thực thi tuyến tính không có rẽ nhánh loại trừ, một đơn hàng giá trị 1.500.000 VNĐ sẽ lần lượt bị trừ 10% rồi lại tiếp tục trừ 15%, gây thất thoát tài chính nghiêm trọng cho doanh nghiệp. Ngược lại, nếu viết các điều kiện rời rạc không đúng cấu trúc, chương trình sẽ tốn chi phí tính toán dư thừa do phải kiểm tra toàn bộ các quy tắc dù điều kiện đầu tiên đã thỏa mãn.

Hình 1.1: So sánh giữa luồng thực thi tuyến tính thụ động và luồng rẽ nhánh điều khiển thông minh trong Python.

Giải pháp cho vấn đề này là áp dụng cấu trúc rẽ nhánh điều khiển (if, elif, else). Cấu trúc này cho phép chương trình đưa ra quyết định thông minh, chỉ thực thi khối lệnh tương ứng với điều kiện thỏa mãn đầu tiên và bỏ qua hoàn toàn các nhánh không liên quan.

2. Cú pháp và cơ chế vận hành câu lệnh rẽ nhánh if, if-else, if-elif-else

2.1. Câu lệnh điều kiện đơn lẻ (if statement)

Câu lệnh if là hình thức rẽ nhánh đơn giản nhất. Khối lệnh bên trong if chỉ được thực thi khi biểu thức điều kiện trả về giá trị biểu thức luận lý là True.

Cú pháp mẫu Python 
if condition:
    # Executed only when condition evaluates to True
statement_block
  • if: Từ khóa bắt đầu một câu lệnh kiểm tra điều kiện trong Python.
  • condition: Biểu thức so sánh hoặc logic trả về giá trị kiểu Booleans (True hoặc False).
  • statement_block: Khối lệnh thực thi phải được lùi lề chính xác 4 khoảng trắng (4 spaces) theo chuẩn PEP 8.

Bài toán nghiệp vụ 2.1

Kiểm tra nếu giá trị đơn hàng vượt quá 500.000 VNĐ thì áp dụng mã miễn phí vận chuyển cho khách hàng.

Cú pháp mẫu Python 
order_amount = 650000
shipping_fee = 30000

if order_amount >= 500000:
    shipping_fee = 0

print(f"Shipping fee: {shipping_fee} VND")

2.2. Cấu trúc rẽ nhánh hai trường hợp (if-else statement)

Cấu trúc if-else cung cấp một đường đi thay thế khi biểu thức điều kiện ban đầu trả về giá trị False. Đảm bảo chương trình luôn thực thi chính xác một trong hai nhánh.

Cú pháp mẫu Python 
if condition:
    # Executed when condition is True
statement_block_1
else:
    # Executed when condition is False
statement_block_2
  • if condition: Nhánh ưu tiên thực thi nếu điều kiện đúng.
  • else: Nhánh mặc định đón nhận tất cả các trường hợp điều kiện sai còn lại, không đi kèm biểu thức điều kiện độc lập nào.

Bài toán nghiệp vụ 2.2

Kiểm tra đơn hàng có đủ hạn mức tối thiểu 200.000 VNĐ để được xử lý giao hàng hay không.

Cú pháp mẫu Python 
order_amount = 150000

if order_amount >= 200000:
    order_status = "Approved"
else:
    order_status = "Rejected - Minimum order requirement not met"

print(f"Order status: {order_status}")

2.3. Cấu trúc rẽ nhánh đa trường hợp loại trừ lẫn nhau (if-elif-else statement)

Khi có nhiều hơn hai kịch bản cần xử lý, từ khóa elif (viết tắt của else if) cho phép kiểm tra chuỗi các điều kiện nối tiếp nhau theo tính chất loại trừ lẫn nhau (Mutually Exclusive).

Cú pháp mẫu Python 
if condition_1:
    statement_block_1
elif condition_2:
    statement_block_2
elif condition_3:
    statement_block_3
else:
    default_statement_block
  • elif condition_n: Điểm kiểm tra phụ chỉ được đánh giá nếu tất cả các điều kiện phía trên nó đều trả về False.
  • default_statement_block: Khối lệnh thực thi cuối cùng nếu không có bất kỳ điều kiện if hay elif nào thỏa mãn.

Bài toán nghiệp vụ 2.3

Phân loại tỷ lệ chiết khấu giảm giá đơn hàng theo các mốc giá trị: từ 1 triệu giảm 15%, từ 500k giảm 10%, từ 200k giảm 5%, dưới 200k không giảm.

Cú pháp mẫu Python 
order_amount = 750000

if order_amount >= 1000000:
    discount_rate = 0.15
elif order_amount >= 500000:
    discount_rate = 0.10
elif order_amount >= 200000:
    discount_rate = 0.05
else:
    discount_rate = 0.0

print(f"Discount rate: {discount_rate * 100}%")

2.4. Cơ chế đánh giá thứ tự từ trên xuống dưới (Top-Down Evaluation)

Python đánh giá chuỗi câu lệnh if-elif-else theo thứ tự nghiêm ngặt từ trên xuống dưới. Ngay khi phát hiện điều kiện đầu tiên trả về True, Python sẽ thực thi ngay khối lệnh tương ứng và ngay lập tức thoát khỏi toàn bộ cấu trúc rẽ nhánh, bỏ qua toàn bộ các biểu thức elif và else phía sau.

3. Các ví dụ ứng dụng thực tiễn

3.1. Ví dụ cơ bản: Kiểm tra đơn hàng đủ điều kiện áp dụng mã miễn phí vận chuyển

Ví dụ tối giản giúp minh họa cách sử dụng câu lệnh if-else để xác định phí giao hàng cho một đơn hàng trực tuyến.

order_amount = 350000
free_shipping_threshold = 300000
standard_shipping_fee = 25000

if order_amount >= free_shipping_threshold:
    actual_shipping_fee = 0
else:
    actual_shipping_fee = standard_shipping_fee

print(f"Order total: {order_amount} VND")
print(f"Shipping fee: {actual_shipping_fee} VND")

3.2. Ví dụ thực tế: Tính toán chiết khấu và phí giao hàng cho đơn hàng e-commerce
Ví dụ thực tế kết hợp kiểm tra phân loại đa mốc bằng if-elif-else để tính số tiền chiết khấu và tổng chi phí thanh toán cuối cùng của khách hàng.

  

    

      
      
      
    

    
order_amount = 680000
base_shipping_fee = 30000

# Evaluate discount tier
if order_amount >= 1000000:
    discount_rate = 0.15
    shipping_discount = 1.0  # 100% free shipping
elif order_amount >= 500000:
    discount_rate = 0.10
    shipping_discount = 0.5  # 50% shipping discount
elif order_amount >= 250000:
    discount_rate = 0.05
    shipping_discount = 0.0
else:
    discount_rate = 0.0
    shipping_discount = 0.0

# Calculate totals
discount_value = order_amount * discount_rate
final_shipping_fee = base_shipping_fee * (1.0 - shipping_discount)
total_payment = (order_amount - discount_value) + final_shipping_fee

print(f"Original Amount: {order_amount:,} VND")
print(f"Discount ({discount_rate * 100}%): -{discount_value:,} VND")
print(f"Shipping Fee: {final_shipping_fee:,} VND")
print(f"Total Payment: {total_payment:,} VND")

3.3. Ví dụ doanh nghiệp (Production Grade): Hệ thống phân hạng ưu đãi đơn hàng đa điều kiện kết hợp tài khoản VIP
Trong các ứng dụng thực tế tại doanh nghiệp, logic rẽ nhánh thường kết hợp các biểu thức điều kiện phức tạp (phép toán logic and, or) và quản lý điểm thưởng tích lũy cho khách hàng thân thiết.

  

    

      
      
      
    

    
order_amount = 1200000
is_vip_member = True
has_promo_code = True

# Determine privilege level
if is_vip_member and order_amount >= 1000000:
    discount_rate = 0.25
    loyalty_points = 500
    badge_label = "VIP Platinum Tier"
elif is_vip_member or order_amount >= 1000000:
    discount_rate = 0.15
    loyalty_points = 200
    badge_label = "Gold Tier"
elif has_promo_code and order_amount >= 300000:
    discount_rate = 0.10
    loyalty_points = 50
    badge_label = "Promo Tier"
else:
    discount_rate = 0.0
    loyalty_points = 10
    badge_label = "Standard Tier"

# Compute final values
net_discount = order_amount * discount_rate
final_price = order_amount - net_discount

print(f"Customer Badge: {badge_label}")
print(f"Order Value: {order_amount:,} VND")
print(f"Net Discount: -{net_discount:,} VND")
print(f"Final Amount: {final_price:,} VND")
print(f"Earned Loyalty Points: +{loyalty_points} pts")

4. Tổng kết và các lưu ý

          

            
 4.1. Lỗi sai thứ tự điều kiện dẫn đến logic bị nuốt (Unreachable Conditions)
Đặt điều kiện tổng quát trước điều kiện cụ thể sẽ khiến các nhánh phía sau không bao giờ được chạm tới.

  

    
      
      
      
      Cú pháp mẫu Python
    
    
  

  
# LỖI: order_amount >= 200000 đứng trước sẽ 'nuốt' mất các mốc lớn hơn!
if order_amount >= 200000:
    discount = 0.05
elif order_amount >= 1000000:  # Không bao giờ chạy được dòng này!
discount = 0.15


Cách khắc phục: Luôn sắp xếp điều kiện theo thứ tự từ chặt chẽ nhất/cao nhất đến tổng quát nhất.
 4.2. Lạm dụng các lệnh if độc lập thay vì chuỗi if-elif-else
Sử dụng nhiều câu lệnh if rời rạc khiến máy tính phải kiểm tra tất cả biểu thức, gây lãng phí hiệu năng và dễ ghi đè sai biến state.

  

    
      
      
      
      Cú pháp mẫu Python
    
    
  

  
# LỖI: Cả 2 lệnh if đều kiểm tra độc lập và ghi đè giá trị!
if order_amount >= 500000:
    discount = 0.10
if order_amount >= 200000:
    discount = 0.05  # Đơn hàng 600k bị hạ giá trị discount xuống 0.05!


 4.3. Quy chuẩn thực hành tốt (Best Practice)
  • Luôn thụt lề đúng 4 khoảng trắng (spaces) theo chuẩn PEP 8. Bắt buộc không dùng tab lẫn khoảng trắng.
  • Viết điều kiện rõ ràng, ưu tiên các biểu thức so sánh đơn giản dễ đọc.
  • Sử dụng nhánh else ở cuối chuỗi để xử lý các dữ liệu ngoại lệ hoặc trường hợp mặc định an toàn.
