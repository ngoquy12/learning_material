1. Tại sao máy tính cần khả năng đưa ra quyết định?

Hãy tưởng tượng bạn đang viết tính năng thanh toán cho một ứng dụng mua sắm trực tuyến như Shopee hay Tiki. Khi khách hàng nhấn nút thanh toán, ứng dụng phải tự động tính toán phí giao hàng và mã giảm giá phù hợp cho từng đơn hàng.

Nếu chương trình máy tính áp đặt cùng một quy tắc cho tất cả mọi người, rắc rối sẽ lập tức xuất hiện! Khách hàng mua đơn lớn 1.500.000 VNĐ sẽ thấy thất vọng vì không được miễn phí giao hàng. Ngược lại, nếu miễn phí vận chuyển cho tất cả mọi đơn, những đơn hàng nhỏ chỉ 20.000 VNĐ sẽ khiến ứng dụng bị lỗ nặng vì tiền phí ship còn cao hơn cả tiền sản phẩm.

Làm sao để máy tính biết tự kiểm tra giá trị từng đơn hàng và đưa ra quyết định phù hợp? Đó chính là lý do chúng ta cần đến các câu lệnh rẽ nhánh điều khiển (if, elif, else) trong Python.

Hình 1.1: Sơ đồ luồng quyết định xử lý hạn mức đơn hàng và ưu đãi trong hệ thống e-commerce.

2. Cú pháp và cơ chế hoạt động của câu lệnh if, if-else, if-elif-else trong Python

2.1. Câu lệnh if đơn (Single If Statement)

Câu lệnh if đánh giá một biểu thức điều kiện kiểu Boolean (True hoặc False). Khối mã bên trong chỉ được thi hành nếu kết quả của điều kiện là True.

Mã nguồn minh họa Python 
if condition:
    # Executed only if condition is True
    statement_block
  • condition: Biểu thức so sánh logic trả về giá trị kiểu dữ liệu Boolean.
  • : (Dấu hai chấm): Ký tự bắt buộc dùng để kết thúc dòng khai báo điều kiện.
  • statement_block: Khối lệnh thực thi phải được thụt lùi vào 4 khoảng trắng (Indentation).

Quy tắc Indentation trong Python: Python không sử dụng dấu đóng mở nhọn {} để phân chia khối lệnh như Java hay C++. Thụt lùi đầu dòng đúng 4 khoảng trắng là bắt buộc để Python xác định mã lệnh thuộc về nhánh nào. 

# Progressive Demo 2.1: Single If Statement
order_amount = 600000
shipping_fee = 30000

if order_amount >= 500000:
    shipping_fee = 0

print(f"Shipping fee: {shipping_fee} VND")

              2.2. Câu lệnh if-else (If-Else Dual Branch)
            

            

              Khi có hai kịch bản loại trừ độc quyền, cấu trúc
              if-else
              đảm bảo chắc chắn đúng một trong hai khối lệnh sẽ được thực thi.
            

            

              

                
                  
                  
                  
                  Mã nguồn minh họa Python
                
                
              

              
if condition:
    # Executed if condition is True
    statement_block_1
else:
    # Executed if condition is False
    statement_block_2

                condition: Điều kiện kiểm tra đầu tiên.
              
    • 
              
  •

                True.

  • 
                else:
                Nhánh mặc định đón nhận tất cả các trường hợp điều kiện là
                False. Nhánh này không chứa biểu thức kiểm tra.
              
    • 
              
  • 
                statement_block_2: Thực thi khi điều kiện kiểm tra ban đầu nhận giá trị

              Control Flow)
            

            

              Đối với bài toán phân loại nhiều cấp độ, Python cung cấp từ khóa
              elif
              (viết tắt của else if). Trình biên dịch sẽ đánh giá các điều kiện

    default_statement_block

                  /
                  condition_3: Các điều kiện bổ sung chỉ được đánh giá nếu tất cả điều kiện
                phía trên là
                False.

  • 
                default_statement_block: Khối lệnh chạy trong trường hợp không có điều kiện

              3.2. Áp dụng thực tế: Phân loại phí vận chuyển với if-else
            

            

              Tính toán phí giao hàng dựa trên ngưỡng giá trị đơn hàng 500,000

order_amount = 320000
standard_shipping_rate = 30000

if order_amount >= 500000:
    actual_shipping_fee = 0
    print("Qualified for free shipping.")
else:
    actual_shipping_fee = standard_shipping_rate
    print(f"Standard shipping rate applied: {actual_shipping_fee} VND.")

total_checkout = order_amount + actual_shipping_fee
print(f"Total checkout amount: {total_checkout} VND")

              3.3. Ví dụ hoàn chỉnh: Tính giảm giá đơn hàng thực tế với if-elif-else
            

            

              Xây dựng tính năng tính tiền đơn hàng hoàn chỉnh, tự động áp dụng mức giảm giá và chính sách miễn phí vận chuyển cho tài khoản VIP.
            

            

              

                

                  
                  
                  
                

                
def process_checkout_pricing(order_amount: float, is_vip_customer: bool) -> dict:
    # 1. Determine shipping fee policy
    if order_amount >= 500000 or is_vip_customer:
        shipping_fee = 0
        shipping_status = "Free Shipping"
    else:
        shipping_fee = 30000
        shipping_status = "Standard Shipping"

    # 2. Mutually exclusive discount evaluation
    if order_amount >= 2000000:
        discount_rate = 0.20
        tier_name = "Tier Gold (20% Off)"
    elif order_amount >= 1000000:
        discount_rate = 0.10
        tier_name = "Tier Silver (10% Off)"
    elif order_amount >= 500000:
        discount_rate = 0.05
        tier_name = "Tier Bronze (5% Off)"
    else:
        discount_rate = 0.00
        tier_name = "Standard (No Discount)"

    # 3. Calculate final amounts
    discount_value = order_amount * discount_rate
    final_total = (order_amount - discount_value) + shipping_fee

    return {
        "tier_name": tier_name,
        "discount_value": discount_value,
        "shipping_fee": shipping_fee,
        "shipping_status": shipping_status,
        "final_total": final_total
    }

# Production call demo
result = process_checkout_pricing(order_amount=1500000, is_vip_customer=False)
print(f"Order Status: {result['tier_name']}")
print(f"Discount: {result['discount_value']} VND")
print(f"Final Amount: {result['final_total']} VND")

            4. Tổng kết và các lưu ý
          

          

            

              

                 4.1. Lỗi
                logic đặt sai thứ tự điều kiện trong chuỗi if-elif-else
              

              

                Vì Python đánh giá biểu thức từ trên xuống dưới, việc xếp điều
                kiện tổng quát (nhỏ hơn) lên trước điều kiện cụ thể (lớn hơn) sẽ
                làm vô hiệu hóa các nhánh phía sau.
              

              

                # LỖI: Đơn hàng 2,500,000 VNĐ sẽ bị lọt vào nhánh >= 500k và
                dừng lại (chỉ giảm 5% thay vì 20%) if order_amount >= 500000:
                discount_rate = 0.05 elif order_amount >= 2000000:
                discount_rate = 0.20
              

            

            

              

                 4.2. Tránh lặp
                code và kiểm tra điều kiện dư thừa (Redundant Conditions)
              

              

                Khi các nhánh đã mang tính loại trừ độc quyền, không cần lặp lại
                điều kiện cận trên ở các câu lệnh
                elif
                tiếp theo.
              

              

                # KHÔNG TỐI ƯU: Điều kiện order_amount < 2000000 là dư thừa
                vì elif chỉ chạy khi if trước đó False elif order_amount >=
                1000000 and order_amount < 2000000: discount_rate = 0.10
              

            

            

              

                 4.3. Quên thụt
                lùi dòng (IndentationError) và lồng ghép quá sâu (Deep Nesting)
              

              

                Quên thụt lùi dòng sau dấu hai chấm
                :
                sẽ trực tiếp gây ra lỗi
                IndentationError
                làm dừng chương trình. Ngoài ra, việc lồng quá 3 cấp
                if
                bên trong một
                if
                khác (Deep Nesting) sẽ làm suy giảm nghiêm trọng tính dễ đọc và
                bảo trì của mã nguồn.
              

            

          

        


        
        

          

            5. Tổng kết và các lưu ý
          


          
          

            

              5.1. Tóm tắt các ý chính
            

            
    
              
  • 
                Câu lệnh if đơn: Sử dụng khi chỉ muốn chạy một khối lệnh khi điều kiện đúng (True), nếu sai chương trình sẽ bỏ qua.
              
    • 
              
  • 
                Câu lệnh if-else: Sử dụng khi bài toán chia làm đúng 2 luồng đối lập (Đúng ➔ Làm nhánh if, Sai ➔ Làm nhánh else).
              
    • 
              
  • 
                Chuỗi if-elif-else: Sử dụng khi kiểm tra nhiều trường hợp từ trên xuống dưới. Ngay khi tìm thấy điều kiện True đầu tiên, Python sẽ chạy nhánh đó và dừng kiểm tra các nhánh sau.
              
    • 
            

          


          
          

            

              5.2. Các lưu ý & Mẹo lập trình (Tips & Tricks)
            

            

              

                

                   Mẹo 1: Viết điều kiện Boolean chuẩn Pythonic
                

                

                  Viết if is_vip: thay vì if is_vip == True:. Mã nguồn vừa ngắn gọn vừa mượt mà.
                

              

              

                

                   Mẹo 2: Đặt điều kiện ngặt nghèo lên trước
                

                

                  Luôn đặt hạn mức giá trị lớn nhất (ví dụ >= 2.000.000) ở đầu chuỗi if để không bị lọt nhánh giảm giá nhỏ hơn.
                

              

            

            

              

                 Lưu ý: Tránh điều kiện dư thừa ở elif
              

              

                Vì nhánh elif chỉ chạy khi if trước đó bị sai, bạn không cần lặp lại vế cận trên (tránh viết elif amount >= 500000 and amount < 2000000:).
