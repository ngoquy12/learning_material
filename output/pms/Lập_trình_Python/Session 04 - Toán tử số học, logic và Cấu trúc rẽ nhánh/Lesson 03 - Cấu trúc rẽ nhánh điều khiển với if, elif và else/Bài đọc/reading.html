Cấu trúc rẽ nhánh điều khiển với if, elif và else

1. Tại sao máy tính cần khả năng đưa ra quyết định?

Hãy tưởng tượng bạn đang viết tính năng thanh toán cho một ứng dụng mua sắm trực tuyến như Shopee hay Tiki. Khi khách hàng nhấn nút thanh toán, ứng dụng phải tự động tính toán phí giao hàng và mã giảm giá phù hợp cho từng đơn hàng.

Nếu chương trình máy tính áp đặt cùng một quy tắc cho tất cả mọi người, rắc rối sẽ lập tức xuất hiện! Khách hàng mua đơn lớn 1.500.000 VNĐ sẽ thấy thất vọng vì không được miễn phí giao hàng. Ngược lại, nếu miễn phí vận chuyển cho tất cả mọi đơn, những đơn hàng nhỏ chỉ 20.000 VNĐ sẽ khiến ứng dụng bị lỗ nặng vì tiền phí ship còn cao hơn cả tiền sản phẩm.

Làm sao để máy tính biết tự kiểm tra giá trị từng đơn hàng và đưa ra quyết định phù hợp? Đó chính là lý do chúng ta cần đến các câu lệnh rẽ nhánh điều khiển (if, elif, else) trong Python.

Hình 1.1: Sơ đồ luồng quyết định xử lý hạn mức đơn hàng và ưu đãi trong hệ thống e-commerce.

2. Cú pháp và cơ chế hoạt động của câu lệnh if, if-else, if-elif-else trong Python

2.1. Câu lệnh if đơn (Single If Statement)

Câu lệnh if đánh giá một biểu thức điều kiện kiểu Boolean (True hoặc False). Khối mã bên trong chỉ được thi hành nếu kết quả của điều kiện là True.

Mã nguồn minh họa Python 
if condition:
    # Khối lệnh chỉ chạy khi điều kiện là True
    statement_block
  • condition: Biểu thức so sánh logic trả về giá trị kiểu dữ liệu Boolean.
  • : (Dấu hai chấm): Ký tự bắt buộc dùng để kết thúc dòng khai báo điều kiện.
  • statement_block: Khối lệnh thực thi phải được thụt lùi vào 4 khoảng trắng (Indentation).

Quy tắc Indentation trong Python: Python không sử dụng dấu đóng mở nhọn {} để phân chia khối lệnh như Java hay C++. Thụt lùi đầu dòng đúng 4 khoảng trắng là bắt buộc để Python xác định mã lệnh thuộc về nhánh nào.

Yêu cầu bài toán (Ví dụ minh họa 2.1):

Cho đơn hàng trị giá 600.000 VNĐ. Kiểm tra nếu giá trị đơn hàng đạt từ 500.000 VNĐ trở lên thì cập nhật phí giao hàng về 0 VNĐ và in phí giao hàng ra màn hình. 

# Ví dụ 2.1: Cấu trúc câu lệnh if đơn
order_amount = 600000
shipping_fee = 30000

# Kiểm tra nếu đơn hàng từ 500.000 VNĐ trở lên thì miễn phí ship
if order_amount >= 500000:
    shipping_fee = 0

print(f"Phí giao hàng: {shipping_fee} VNĐ")

            3. Các ví dụ ứng dụng thực tiễn
          

          

            

              3.1. Cú pháp cơ bản: Kiểm tra điều kiện đơn với lệnh if
            

            

              Ví dụ dưới đây thể hiện cú pháp kiểm tra cơ bản cho trường hợp áp
              dụng ưu đãi đặc biệt nếu người dùng là khách hàng VIP.
            

            

              

                 Yêu cầu
                bài toán (Ví dụ ứng dụng 3.1):
              

              

                Cho khách hàng là tài khoản VIP (is_vip_customer = True). Hãy kiểm tra điều kiện nếu là tài khoản VIP thì cập nhật phí
                giao hàng về
                0 VNĐ
                và in ra kết quả.
              

            

            

              

                

                  
                  
                  
                

                
# Ví dụ 3.1: Kiểm tra khách hàng VIP
is_vip_customer = True
shipping_fee = 30000

# Nếu là tài khoản VIP thì miễn phí giao hàng
if is_vip_customer:
    shipping_fee = 0

print(f"Phí giao hàng: {shipping_fee} VNĐ")

              3.2. Áp dụng thực tế: Phân loại phí vận chuyển với if-else
            

            

              Tính toán phí giao hàng dựa trên ngưỡng giá trị đơn hàng 500,000
              VNĐ. Khách hàng sẽ nhận mức phí ship tương ứng chính xác.
            

            

              

                 Yêu cầu
                bài toán (Ví dụ ứng dụng 3.2):
              

              

                Cho đơn hàng trị giá
                320.000 VNĐ. Nếu đơn hàng từ
                500.000 VNĐ
                trở lên thì miễn phí ship (0 VNĐ), ngược lại tính phí ship tiêu chuẩn
                30.000 VNĐ. Tính toán tổng chi phí đơn hàng.
              

            

            

              

                

                  
                  
                  
                

                
# Ví dụ 3.2: Phân loại phí giao hàng
order_amount = 320000
standard_shipping_rate = 30000

if order_amount >= 500000:
    actual_shipping_fee = 0
    print("Đủ điều kiện miễn phí giao hàng.")
else:
    actual_shipping_fee = standard_shipping_rate
    print(f"Áp dụng phí giao hàng tiêu chuẩn: {actual_shipping_fee} VNĐ.")

total_checkout = order_amount + actual_shipping_fee
print(f"Tổng tiền thanh toán: {total_checkout} VNĐ")

              3.3. Ví dụ hoàn chỉnh: Tính giảm giá đơn hàng thực tế với
              if-elif-else
            

            

              Xây dựng tính năng tính tiền đơn hàng hoàn chỉnh, tự động áp dụng
              mức giảm giá và chính sách miễn phí vận chuyển cho tài khoản VIP.
            

            

              

                 Yêu cầu
                bài toán (Ví dụ ứng dụng 3.3):
              

              

                Lập trình tính năng tính tiền hoàn chỉnh cho đơn hàng
                1.500.000 VNĐ: vừa kiểm tra miễn phí vận chuyển (nếu từ
                500k
                trở lên hoặc là khách VIP), vừa tự động phân hạng giảm giá
                (5%,
                10%,
                20%), sau đó in hóa đơn thanh toán chi tiết.
              

            

            

              

                

                  
                  
                  
                

                
# Ví dụ 3.3: Tính giảm giá và phí giao hàng cho đơn hàng
order_amount = 1500000
is_vip_customer = False

# 1. Kiểm tra chính sách miễn phí giao hàng
if order_amount >= 500000 or is_vip_customer:
    shipping_fee = 0
    shipping_status = "Miễn phí giao hàng"
else:
    shipping_fee = 30000
    shipping_status = "Phí giao hàng tiêu chuẩn"

# 2. Xử lý mức giảm giá theo hạn mức đơn hàng
if order_amount >= 2000000:
    discount_rate = 0.20
    tier_name = "Hạng Vàng (Giảm 20%)"
elif order_amount >= 1000000:
    discount_rate = 0.10
    tier_name = "Hạng Bạc (Giảm 10%)"
elif order_amount >= 500000:
    discount_rate = 0.05
    tier_name = "Hạng Đồng (Giảm 5%)"
else:
    discount_rate = 0.00
    tier_name = "Hạng Tiêu chuẩn (Không giảm giá)"

# 3. Tính toán số tiền thanh toán cuối cùng
discount_value = order_amount * discount_rate
final_total = (order_amount - discount_value) + shipping_fee

print(f"Hạng ưu đãi: {tier_name}")
print(f"Số tiền giảm: {discount_value} VNĐ")
print(f"Phí vận chuyển: {shipping_fee} VNĐ ({shipping_status})")
print(f"Tổng tiền thanh toán: {final_total} VNĐ")

              Kiến thức trọng tâm
            

            
    
              
  • 
                Câu lệnh
                  if
                  đơn:
                Sử dụng khi chỉ muốn thực hiện một khối lệnh khi điều kiện đúng
                (True), nếu sai chương trình sẽ bỏ qua.
              
    • 
              
  • 
                Câu lệnh
                  if-else:
                Sử dụng khi bài toán chia làm đúng 2 luồng đối lập (Đúng ➔ Làm
                nhánh
                if, Sai ➔ Làm nhánh
                else).
              
    • 
              
  • 
                Chuỗi
                  if-elif-else:
                Sử dụng khi kiểm tra nhiều trường hợp từ trên xuống dưới. Ngay
                khi tìm thấy điều kiện
                True
                đầu tiên, Python sẽ chạy nhánh đó và dừng kiểm tra các nhánh
                sau.

              Các lỗi thường gặp & Lưu ý thực tế
            

            

              

                 Lỗi
                logic đặt sai thứ tự điều kiện trong chuỗi if-elif-else
              

              

                Vì Python đánh giá biểu thức từ trên xuống dưới, việc xếp điều
                kiện tổng quát (nhỏ hơn) lên trước điều kiện cụ thể (lớn hơn) sẽ
                làm vô hiệu hóa các nhánh phía sau.
              

              

                # LỖI: Đơn hàng 2.500.000 VNĐ sẽ bị lọt vào nhánh >= 500k và
                dừng lại (chỉ giảm 5% thay vì 20%)

                if order_amount >= 500000:

                    discount_rate = 0.05

                elif order_amount >= 2000000:

                    discount_rate = 0.20
              

            

            

              

                 Tránh lặp code
                và kiểm tra điều kiện dư thừa

                cận trên ở các câu lệnh
                elif
                tiếp theo.
              

              

                # KHÔNG TỐI ƯU: Điều kiện order_amount < 2000000 là dư
                thừa

                elif order_amount >= 1000000 and order_amount <
                2000000:

                    discount_rate = 0.10
              

            

            

              

                 Quên thụt lùi
                dòng (IndentationError) và lồng ghép quá sâu

                :
                sẽ trực tiếp gây ra lỗi

                làm dừng chương trình. Ngoài ra, việc lồng quá 3 cấp
                if
                bên trong một
                if
                khác (Deep Nesting) sẽ làm suy giảm tính dễ đọc và bảo trì của
                mã nguồn.

                kiện Boolean chuẩn Pythonic

                if is_vip:
