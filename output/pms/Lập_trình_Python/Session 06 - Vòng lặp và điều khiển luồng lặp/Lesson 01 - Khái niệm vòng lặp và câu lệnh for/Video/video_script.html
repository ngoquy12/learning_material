Sử dụng Hàm range() với Vòng lặp for

Chỉ dẫn thao tác studio
Cam 2 (IDE Screen)
Hiển thị Slide 3: Hàm range() trong Python Minh họa các tham số range(start, stop, step) 
# range(stop)
for i in range(5):
    print(i)  # In từ 0 đến 4

# range(start, stop, step)
for i in range(1, 10, 2):
    print(i)  # In các số lẻ: 1, 3, 5, 7, 9

Một công cụ rất phổ biến / đi kèm với vòng lặp for / chính là hàm range(). // Hàm range() giúp tạo ra một dãy số liên tục. // Nếu chúng ta viết range(5), / Python sẽ sinh ra dãy số từ 0 đến 4. // Ngoài ra, / hàm range() còn nhận vào 3 tham số: start - giá trị bắt đầu, stop - giá trị kết thúc không bao gồm, / và step - bước nhảy. // Ví dụ range(1, 10, 2) / sẽ duyệt qua các số lẻ từ 1 đến 9.
