1. (Session 06 - Cấu trúc Điều kiện và Rẽ nhánh Quyết định với if, else, switch-case):

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Cấu trúc `if...else if...else` cho phép rẽ nhánh logic dựa trên các biểu thức điều kiện so sánh (điểm tín dụng, thu nhập hàng tháng) trả về giá trị Boolean.
  • Cấu trúc `switch-case` tối ưu hóa việc phân luồng khi so sánh một biến với nhiều giá trị rời rạc cụ thể (như phân hạng tín nhiệm AAA, AA, B, C).
  • Nguyên lý đánh giá ngắn mạch (short-circuit) và ép kiểu ngầm định (coercion) quyết định cách JavaScript đánh giá tính đúng/sai (truthy/falsy) trong biểu thức điều kiện.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Quên từ khóa `break` trong các khối `case` của `switch` gây ra lỗi trôi lệnh (fall-through), khiến chương trình thực thi nhầm các nhánh logic phía dưới.

Lỗi so sánh bằng toán tử yếu `==` thay vì toán tử chặt `===`, dẫn đến việc chuỗi thu nhập bị ép kiểu tự động và bỏ qua kiểm tra lỗi kiểu dữ liệu.

Trực quan: Xét duyệt Đơn vay Tín dụng

script.js
LIVE PREVIEW 
// --- Bước 1: Kiểm tra điều kiện đầu vào & Điểm tín dụng cơ bản ---
let isEligibleBasic = false;
if (typeof credit_score !== 'number' || isNaN(credit_score)) {
  console.log("Cảnh báo: Điểm tín dụng không hợp lệ!");
} else if (credit_score >= 650 && monthly_income >= 10000000) {
  isEligibleBasic = true;
} else {
  isEligibleBasic = false;
}

// --- Bước 2: Phân hạng quy trình xét duyệt bằng Switch-Case ---
let maxLoanLimit = 0;
let approvalStatus = "Từ chối";

if (isEligibleBasic) {
  switch (customer_rank.toUpperCase()) {
    case 'AAA':
      maxLoanLimit = monthly_income * 20;
      approvalStatus = "Được duyệt ưu đãi đặc biệt";
      break;
    case 'AA':
      maxLoanLimit = monthly_income * 10;
      approvalStatus = "Được duyệt hạn mức chuẩn";
      break;
    case 'B':
      maxLoanLimit = monthly_income * 5;
      approvalStatus = "Được duyệt hạn mức cơ bản";
      break;
    default:
      maxLoanLimit = 0;
      approvalStatus = "Yêu cầu bổ sung tài sản thế chấp";
      break;
  }
}

// --- Bước 3: Tổng hợp kết quả phê duyệt tín dụng ---
const resultMessage = `Trạng thái: ${approvalStatus} | Hạn mức đề xuất: ${maxLoanLimit.toLocaleString('vi-VN')} VNĐ`;
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Kiểm tra credit_score (720 >= 650) và monthly_income (25tr >= 10tr) thỏa mãn -> isEligibleBasic = true.
> 2. Bước 2: Chạy switch-case với hạng 'AA' -> Tính hạn mức = 25.000.000 * 10 = 250.000.000 VNĐ.
> 3. Bước 3: Định dạng kết quả thông báo approvalStatus = 'Được duyệt hạn mức chuẩn' và hạn mức 250.000.000 VNĐ.
Kết quả đánh giá Trạng thái: Được duyệt hạn mức chuẩn | Hạn mức đề xuất: 250.000.000 VNĐ

2. Câu lệnh Điều kiện if và Cấu trúc if-else

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Cú pháp & Khối lệnh {}: Câu lệnh if-else đánh giá biểu thức điều kiện trả về giá trị Booleans (true/false). Khối lệnh {} giúp gom nhóm nhiều câu lệnh thực thi và xác định phạm vi biến (block scope), luôn dùng {} để mã nguồn rõ ràng và tránh lỗi thực thi ngoài ý muốn.
  • Rẽ nhánh nhiều điều kiện (if ... else if ... else): Cho phép kiểm tra nhiều tiêu chí logic theo thứ tự từ trên xuống dưới. Khi gặp điều kiện đầu tiên thỏa mãn (true), khối lệnh tương ứng sẽ thực thi và trình tự rẽ nhánh kết thúc ngay lập tức.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bỏ sót cặp dấu ngoặc nhọn {}: Khi viết if không dùng {}, câu lệnh if chỉ kiểm tra và điều khiển duy nhất 1 dòng lệnh tiếp theo. Các dòng bên dưới sẽ luôn thực thi bất chấp điều kiện đúng hay sai, gây ra sai sót logic nghiêm trọng trong quy trình nghiệp vụ.

Nhầm lẫn giữa phép gán (=) và phép so sánh (===): Sử dụng nhầm if (creditScore = 700) sẽ gán lại giá trị 700 cho biến (trả về giá trị truthy) thay vì so sánh, làm cho điều kiện luôn đúng và duyệt sai hồ sơ.

Trực quan: Xét Duyệt Đơn Vay Tín Dụng

script.js
LIVE PREVIEW 
// --- Bước 1: Kiểm tra điều kiện nợ xấu / điểm tín dụng tối thiểu --- 
let resultStatus = "";
let maxLoanAmount = 0;

if (creditScore < 500) {
    resultStatus = "Từ chối: Điểm tín dụng quá thấp";
    maxLoanAmount = 0;
} else {
    // --- Bước 2: Rẽ nhánh phân loại khách hàng & tính hạn mức --- 
    if (creditScore >= 750 && monthlyIncome >= 15000000) {
        resultStatus = "Phê duyệt Hạn mức VIP";
        maxLoanAmount = monthlyIncome * 10;
    } else if (creditScore >= 600 && monthlyIncome >= 8000000) {
        resultStatus = "Phê duyệt Hạn mức Tiêu chuẩn";
        maxLoanAmount = monthlyIncome * 5;
    } else {
        resultStatus = "Yêu cầu Tài sản Bảo đảm";
        maxLoanAmount = monthlyIncome * 2;
    }
}

// --- Bước 3: Xuất kết quả xét duyệt hồ sơ tín dụng --- 
console.log(`Kết quả: ${resultStatus} | Hạn mức: ${maxLoanAmount} VNĐ`);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Điểm CIC creditScore (720) >= 500, điều kiện nợ xấu (creditScore < 500) trả về false => Chuyển sang khối else chính.
> 2. Bước 2: Kiểm tra nhánh 1: (720 >= 750) là false. Chuyển sang kiểm tra nhánh 2: (720 >= 600) AND (20tr >= 8tr) trả về true => Đạt Hạn mức Tiêu chuẩn.
> 3. Bước 3: Tính toán hạn mức cho vay (20tr x 5 = 100tr VNĐ) và ghi nhận kết quả phê duyệt thành công.
Kết quả đánh giá Phê duyệt Hạn mức Tiêu chuẩn (100.000.000 VNĐ)

3. Câu lệnh Rẽ nhánh Nhiều Trường hợp switch-case

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Cấu trúc `switch-case` kiểm tra một giá trị biến với danh sách các trường hợp `case` cụ thể bằng so sánh tuyệt đối nghiêm ngặt (`===`).
  • Mỗi khối `case` sử dụng từ khóa `break` để kết thúc thực thi và thoát khỏi rẽ nhánh; khối `default` đảm nhận xử lý khi không có `case` nào trùng khớp.
  • Tích hợp công cụ thực thi Node.js runtime, Live Server và trợ lý AI IDE giúp sinh mã boilerplate nhanh chóng để kiểm thử các luồng quyết định ngân hàng.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy trôi lệnh (Fall-through): Nếu quên viết `break`, chương trình sẽ tự động chạy tiếp các câu lệnh ở `case` phía dưới dù không hề khớp điều kiện.

Bẫy ép kiểu dữ liệu: `switch-case` so sánh nghiêm ngặt cả giá trị và kiểu dữ liệu (ví dụ: số `1` và chuỗi `'1'` là khác nhau), dễ làm rơi vào nhánh `default` ngoài ý muốn.

Trực quan: Phân loại Hạn mức Vay switch-case

script.js
LIVE PREVIEW 
// --- Bước 1: Tiếp nhận mã hạng tín dụng và số tiền vay đề xuất ---
const customerTier = "GOLD"; // Các hạng: BRONZE, SILVER, GOLD, PLATINUM
const requestedLoan = 500000000; // Số tiền vay: 500.000.000 VNĐ

let maxLoanLimit = 0;
let interestRate = 0;
let tierName = "";

// --- Bước 2: Rẽ nhánh switch-case xác định chính sách tín dụng ---
switch (customerTier) {
  case "BRONZE":
    tierName = "Khách hàng Đồng";
    maxLoanLimit = 100000000;
    interestRate = 12.5;
    break;
  case "SILVER":
    tierName = "Khách hàng Bạc";
    maxLoanLimit = 300000000;
    interestRate = 10.5;
    break;
  case "GOLD":
    tierName = "Khách hàng Vàng";
    maxLoanLimit = 800000000;
    interestRate = 8.5;
    break;
  case "PLATINUM":
    tierName = "Khách hàng Bạch Kim";
    maxLoanLimit = 2000000000;
    interestRate = 6.5;
    break;
  default:
    tierName = "Hạng không xác định";
    maxLoanLimit = 0;
    interestRate = 0;
}

// --- Bước 3: Đánh giá khả năng phê duyệt đơn vay ---
const isApproved = maxLoanLimit > 0 && requestedLoan <= maxLoanLimit;
const resultMessage = isApproved
  ? `Duyệt vay ${requestedLoan.toLocaleString("vi-VN")} VNĐ (${tierName}, Lãi suất: ${interestRate}%/năm)`
  : `Từ chối vay (${tierName}: Hạn mức tối đa ${maxLoanLimit.toLocaleString("vi-VN")} VNĐ)`;
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Tiếp nhận mã hạng customerTier = 'GOLD' và số tiền đề nghị vay requestedLoan = 500,000,000 VNĐ.
> 2. Bước 2: Câu lệnh switch khớp với 'case GOLD', gán hạn mức maxLoanLimit = 800,000,000 VNĐ và lãi suất interestRate = 8.5%, thoát rẽ nhánh bằng break.
> 3. Bước 3: So sánh 500,000,000 <= 800,000,000 trả về true -> Phê duyệt đơn vay thành công.
Kết quả đánh giá Duyệt vay 500.000.000 VNĐ (Khách hàng Vàng, Lãi suất: 8.5%/năm)

4. Biểu thức Điều kiện Ba ngôi Ternary Operator

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Toán tử ba ngôi (Ternary Operator) với cú pháp `điều_kiện ? biểu_thức_1 : biểu_thức_2` là dạng rút gọn của cấu trúc `if-else` trong JavaScript (ES6+).
  • Hoạt động như một biểu thức (expression) trả về giá trị trực tiếp, thích hợp để khởi tạo hoặc gán giá trị nhanh cho biến trong các logic ngân hàng.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Lạm dụng lồng ghép nhiều toán tử ba ngôi (Nested Ternary) làm code trở nên rối rắm, khó bảo trì và dễ gây ra sai sót trong logic nghiệp vụ.

Sử dụng toán tử ba ngôi cho các lệnh thay đổi trạng thái (side-effects) hoặc không trả về giá trị thay vì dùng `if-else` truyền thống.

Trực quan: Xét duyệt Đơn vay Ba ngôi

script.js
LIVE PREVIEW 
// --- Bước 1: Tiếp nhận dữ liệu & Kiểm tra điều kiện thu nhập tối thiểu --- 
const isIncomeQualified = monthlyIncome >= 15000000 ? true : false;

// --- Bước 2: Phân loại rủi ro tín dụng theo điểm CIC --- 
const creditTier = creditScore >= 700 ? "Tín dụng Tốt" : "Tín dụng Rủi ro";

// --- Bước 3: Quyết định phê duyệt hồ sơ đơn vay ngân hàng --- 
const approvalStatus = (isIncomeQualified && creditScore >= 700) 
  ? "Được phê duyệt tự động" 
  : "Cần thẩm định thủ công";
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Thu nhập 25,000,000 VNĐ >= 15,000,000 VNĐ -> isIncomeQualified = true.
> 2. Bước 2: Điểm tín dụng 720 >= 700 -> creditTier = 'Tín dụng Tốt'.
> 3. Bước 3: Đạt cả 2 điều kiện -> approvalStatus = 'Được phê duyệt tự động'.
