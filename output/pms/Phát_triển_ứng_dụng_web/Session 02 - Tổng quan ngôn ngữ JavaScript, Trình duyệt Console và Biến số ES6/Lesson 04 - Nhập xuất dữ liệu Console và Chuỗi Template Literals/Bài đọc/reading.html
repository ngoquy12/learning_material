Nhập xuất dữ liệu Console và Chuỗi Template Literals

1. Thách thức trong thu thập dữ liệu và xuất hóa đơn rạp chiếu phim TRUEMAX

Hãy tưởng tượng bạn đang lập trình phân hệ xuất hóa đơn đặt vé tự động cho hệ thống rạp chiếu phim TRUEMAX. Khi khách hàng mua vé tại quầy hoặc ứng dụng, hệ thống cần thu thập tên khách hàng, tên phim, số lượng vé và giá vé đơn lẻ, sau đó tính tổng tiền và in hóa đơn thanh toán cho khách hàng.

Vấn đề phát sinh khi tất cả dữ liệu thu thập qua các hộp thoại nhập liệu trình duyệt (hàm prompt()) đều tự động chuyển thành dạng chuỗi ký tự (String). Nếu người dùng nhập số lượng vé là "2" và giá vé là "120000", phép cộng tài chính "120000" + "15000" (phụ thu ghế đôi) sẽ cho ra kết quả nối chuỗi kỳ quặc là "12000015000" thay vì 135.000 VNĐ. Thêm vào đó, việc ghép các biến vào hóa đơn bằng cách cộng chuỗi truyền thống khiến mã nguồn trở nên rối rắm và rất dễ gặp lỗi xuống dòng.

Làm thế nào để ứng dụng chuyển đổi dữ liệu nhập vào thành dạng số chính xác và định dạng hóa đơn đẹp mắt, chuyên nghiệp? Đó chính là lý do chúng ta cần làm chủ bộ công cụ Nhập xuất dữ liệu Browser I/O, Ép kiểu dữ liệu (Type Casting) và Chuỗi Template Literals trong JavaScript.

2. Cú pháp và cơ chế nhập xuất dữ liệu, ép kiểu và Template Literals trong JavaScript

2.1. Nhập và xuất dữ liệu với Browser I/O và Console

JavaScript cung cấp các hàm tương tác trực tiếp với giao diện trình duyệt (Browser I/O) và môi trường phát triển (Console Log). Các hàm này là công cụ cơ bản giúp lập trình viên trao đổi dữ liệu với người dùng và kiểm định trạng thái ứng dụng.

Mã nguồn minh họa Javascript 
// 1. Nhận chuỗi nhập từ người dùng qua pop-up trình duyệt
const userInput = prompt("Message prompt string.");

// 2. Hộp thoại thông báo pop-up trực tiếp
alert("Popup message string.");

// 3. Ghi log debug hệ thống ra tab Console của DevTools
console.log("Standard output:", userInput);
console.warn("Warning output message.");
console.error("Error output message.");
console.table(objectOrArray);
  • prompt(): Hiển thị một cửa sổ hộp thoại chứa thông điệp và một ô nhập văn bản. Giá trị trả về từ hàm này luôn luôn là kiểu String (chuỗi ký tự). Nếu người dùng bấm "Hủy" (Cancel), hàm trả về null.
  • alert(): Hiển thị một hộp thoại thông báo kèm nút "OK". Hàm này dừng toàn bộ luồng thực thi của trang web cho đến khi người dùng bấm đóng hộp thoại.
  • console.log(): Ghi nhận dữ liệu thông thường ra công cụ Developer Console của trình duyệt. Quá trình này không làm gián đoạn trải nghiệm người dùng trên màn hình.
  • console.warn() và console.error(): Xuất ra các dòng log cảnh báo màu vàng hoặc báo lỗi màu đỏ giúp lập trình viên khoanh vùng sự cố nhanh chóng.
  • console.table(): Trình bày dữ liệu dạng đối tượng (Object) hoặc mảng (Array) thành một bảng chỉ mục chuyên nghiệp, trực quan.

3. Các ví dụ ứng dụng thực tiễn

3.1. Ví dụ 3.1: Nhận thông tin đặt vé và in xác nhận đơn giản

Ví dụ cơ bản minh họa việc thu thập dữ liệu tên khách hàng và số lượng vé từ hộp thoại prompt(), ép kiểu số lượng vé bằng parseInt() và xuất câu xác nhận bằng Template Literals.

Yêu cầu bài toán:

Yêu cầu người dùng nhập tên khách hàng và số lượng vé muốn mua qua prompt(). Ép kiểu số lượng vé sang kiểu số nguyên, sau đó in ra thông báo xác nhận đặt vé đơn giản bằng console.log() và Template Literals.

Mã nguồn minh họa Javascript 
// Bước 1: Nhận dữ liệu đầu vào từ người dùng qua prompt()
const inputCustomerName = prompt("Mời bạn nhập tên khách hàng:");
const inputTicketCount = prompt("Mời bạn nhập số lượng vé cần mua:");

// Bước 2: Ép kiểu dữ liệu từ String sang Number bằng parseInt()
const ticketCount = parseInt(inputTicketCount, 10);

// Bước 3: Tạo thông báo xác nhận bằng Template Literals
const confirmationMessage = `[XÁC NHẬN VÉ] Khách hàng ${inputCustomerName} đã đăng ký mua ${ticketCount} vé thành công.`;

// Bước 4: Xuất kết quả ra Console
console.log(confirmationMessage);

3.2. Ví dụ 3.2: Tính toán hóa đơn đặt vé nhiều dòng với chiết khấu

Mở rộng tính năng bằng cách tiếp nhận đầy đủ thông tin tên phim, đơn giá và tỷ lệ chiết khấu. Tiến hành ép kiểu đầy đủ và dựng hóa đơn nhiều dòng có khoảng cách căn chỉnh đẹp mắt.

Yêu cầu bài toán:

Mở rộng hệ thống: Nhận thêm tên phim, đơn giá vé và tỷ lệ giảm giá (%) từ người dùng. Thực hiện ép kiểu đầy đủ cho các số liệu, tính tổng tiền trước thuế, số tiền được giảm giá và tổng tiền thanh toán cuối cùng. Xuất hóa đơn đẹp dạng bảng nhiều dòng bằng Template Literals.

Mã nguồn minh họa Javascript 
// Bước 1: Thu thập thông tin đầu vào
const customerName = prompt("Nhập tên khách hàng:");
const movieTitle = prompt("Nhập tên phim:");
const rawQuantity = prompt("Nhập số lượng vé:");
const rawUnitPrice = prompt("Nhập giá vé đơn lẻ (VNĐ):");
const rawDiscountRate = prompt("Nhập tỷ lệ giảm giá (%):");

// Bước 2: Ép kiểu dữ liệu đầu vào sang kiểu số
const quantity = parseInt(rawQuantity, 10);
const unitPrice = parseFloat(rawUnitPrice);
const discountRate = parseFloat(rawDiscountRate);

// Bước 3: Thực hiện tính toán nghiệp vụ
const subTotal = quantity * unitPrice;
const discountAmount = subTotal * (discountRate / 100);
const finalTotal = subTotal - discountAmount;

// Bước 4: Dựng hóa đơn chi tiết sử dụng Template Literals nhiều dòng
const detailedReceipt = `
========================================
       RẠP CHẾU PHIM TRUEMAX CINEMA      
========================================
Khách hàng   : ${customerName}
Phim         : ${movieTitle}
----------------------------------------
Số lượng vé  : ${quantity} vé
Đơn giá      : ${unitPrice.toLocaleString("vi-VN")} VNĐ
Tạm tính     : ${subTotal.toLocaleString("vi-VN")} VNĐ
Giảm giá     : -${discountAmount.toLocaleString("vi-VN")} VNĐ (${discountRate}%)
----------------------------------------
TỔNG THANH TOÁN: ${finalTotal.toLocaleString("vi-VN")} VNĐ
========================================
`;

// Bước 5: In kết quả ra Console và hiển thị alert
console.log(detailedReceipt);
alert(`Đặt vé thành công! Tổng tiền cần thanh toán: ${finalTotal.toLocaleString("vi-VN")} VNĐ`);

3.3. Ví dụ 3.3: Xử lý dữ liệu đầu vào an toàn và cảnh báo lỗi hệ thống

Hoàn thiện phân hệ nghiệp vụ doanh nghiệp: Sử dụng giá trị dự phòng mặc định (Fallback values) và kiểm tra lỗi ép kiểu bằng Number.isNaN() để ngăn chặn hiện tượng hóa đơn bị hư hại dữ liệu.

Yêu cầu bài toán:

Hoàn thiện phân hệ đặt vé doanh nghiệp: Kiểm tra xem các giá trị nhập vào có hợp lệ hay không (tránh lỗi NaN khi ép kiểu thất bại). 4. Tổng kết bài học & Các lỗi thường gặp

4.1. Kiến thức trọng tâm

  • Cửa sổ nhập liệu prompt() luôn trả về giá trị kiểu String. Phải sử dụng parseInt() hoặc parseFloat() trước khi tính toán số học.
  • Hàm parseInt(str, 10) luôn luôn cần truyền cơ số 10 làm tham số thứ hai để đảm bảo ép kiểu hệ thập phân chuẩn xác.
  • Template Literals sử dụng dấu nháy ngược ` ` giúp viết chuỗi nhiều dòng và nhúng biểu thức nội suy ${expression} cực kỳ ngắn gọn.
  • Sử dụng console.table() để hiển thị dữ liệu hóa đơn dạng bảng chuyên nghiệp trong DevTools.

4.2. Các lỗi thường gặp & Lưu ý thực tế

Lỗi 1: Phép nối chuỗi ngoài ý muốn do quên ép kiểu dữ liệu từ prompt()

Khi sử dụng toán tử cộng + giữa các giá trị lấy trực tiếp từ prompt(), JavaScript sẽ hiểu nhầm là phép nối hai chuỗi ký tự thay vì phép cộng số học.

// Mã nguồn vi phạm:
const ticketPrice = prompt("Nhập giá vé:"); // "100000"
const surcharge = prompt("Nhập phụ thu:"); // "15000"
const totalCost = ticketPrice + surcharge; // Trả về "10000015000" (Sai sót nghiêm trọng!)
// Cách khắc phục chuẩn:
const totalCost = Number(ticketPrice) + Number(surcharge); // Trả về 115000

Lỗi 2: Dùng sai dấu nháy khiến Template Literals không hoạt động

Cú pháp nội suy ${expression} chỉ hoạt động khi chuỗi được bao bọc bởi cặp dấu Backtick ` `. Nếu dùng nháy đơn hay nháy kép, biểu thức sẽ bị coi là văn bản thuần túy.

// Mã nguồn vi phạm:
const customerName = "Nguyễn Văn A";
const message = "Xin chào ${customerName}, chúc bạn xem phim vui vẻ!"; // In nguyên văn chữ ${customerName}
// Cách khắc phục chuẩn:
const message = `Xin chào ${customerName}, chúc bạn xem phim vui vẻ!`; // In ra "Xin chào Nguyễn Văn A..."
