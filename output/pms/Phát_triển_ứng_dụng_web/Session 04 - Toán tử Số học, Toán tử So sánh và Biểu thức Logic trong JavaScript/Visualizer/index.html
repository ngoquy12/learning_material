1. Toán tử Số học và Toán tử Gán gộp

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Toán tử số học (+, -, *, /, %, **): Thực hiện tính toán giá trị số trong giỏ hàng (tổng tiền hàng, tính dư quà tặng với phép chia lấy dư %, lũy thừa điểm thưởng **).
  • Toán tử gán gộp (+=, -=, *=, /=): Viết ngắn gọn thao tác cập nhật biến (ví dụ: grandTotal += shippingFee để cộng bù phí vận chuyển, -= để trừ voucher).
  • Toán tử tăng/giảm (++ / --): Thay đổi nhanh số lượng sản phẩm trong giỏ (phân biệt ++x tăng trước khi gán và x++ tăng sau khi trả về giá trị).

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy toán tử + và nối chuỗi: Khi nhận dữ liệu từ input HTML (dạng string), phép cộng `+` sẽ thực hiện nối chuỗi thay vì cộng số (ví dụ: '150000' + 30000 = '15000030000'). Lỗi này khiến tổng thanh toán tăng vọt bất thường.

Bẫy tiền tố/hậu tố trong biểu thức (++x vs x++): Sử dụng `currentCartCount++` trong biểu thức tính toán sẽ lấy giá trị cũ trước khi tăng 1 đơn vị, dẫn đến tính sai số lượng sản phẩm thanh toán thực tế.

Trực quan: Tính toán Đơn hàng Checkout

script.js
LIVE PREVIEW 
// --- Bước 1: Khai báo & Phép toán số học cơ bản (*, %, **) ---
let unitPrice = Number(params.unitPrice); // Đơn giá sản phẩm (VNĐ)
let quantity = Number(params.quantity);   // Số lượng đặt mua
let subtotal = unitPrice * quantity;      // Tính tiền hàng cơ bản
let comboRemainder = quantity % 2;        // Chia dư kiểm tra mua theo cặp quà tặng
let rewardPoints = quantity ** 2;         // Điểm thưởng tích lũy (lũy thừa)

// --- Bước 2: Áp dụng gán gộp cập nhật phí & giảm giá (+=, -=) ---
let grandTotal = subtotal;
let shippingFee = Number(params.shippingFee);
let voucherDiscount = Number(params.voucherDiscount);

grandTotal += shippingFee;     // Gán gộp: Cộng thêm phí ship vào tổng thanh toán
grandTotal -= voucherDiscount; // Gán gộp: Trừ tiền voucher giảm giá

// --- Bước 3: Thao tác tăng/giảm số lượng & Chốt bill (++ / --) ---
let currentCartCount = quantity;
currentCartCount++; // Thêm 1 sản phẩm dùng thử tặng kèm tự động
let finalBill = grandTotal; // Tổng thanh toán đơn hàng thành công
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Tính subtotal = 150.000 * 3 = 450.000 VNĐ. Phép dư 3 % 2 = 1 (dư 1 sản phẩm). Điểm thưởng 3 ** 2 = 9 điểm.
> 2. Bước 2: Gán gộp grandTotal += 30.000 (thành 480.000 VNĐ), sau đó grandTotal -= 50.000 (còn 430.000 VNĐ).
> 3. Bước 3: Tăng currentCartCount++ thành 4 món (gồm 1 món tặng). Kết quả thanh toán finalBill = 430.000 VNĐ.
Kết quả đánh giá 430,000 VNĐ (Tổng 4 sản phẩm)

2. Toán tử So sánh Bằng nghiêm ngặt (===) và Khác (!==)

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Toán tử so sánh bằng nghiêm ngặt (===) và khác nghiêm ngặt (!==) kiểm tra đồng thời cả Giá trị (Value) lẫn Kiểu dữ liệu (Data Type) của hai vế.
  • Khác với so sánh lỏng lẻo (==, !=), toán tử nghiêm ngặt KHÔNG thực hiện ép kiểu ngầm định (Type Coercion), giúp đảm bảo tính chính xác tuyệt đối khi xác thực dữ liệu giỏ hàng.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy dữ liệu từ DOM HTML Input: Giá trị thu được từ ô nhập liệu luôn là kiểu String (vd: "2"). Nếu so sánh trực tiếp "2" === 2 sẽ trả về false, dẫn đến lỗi logic kiểm tra điều kiện thanh toán.

Bẫy ép kiểu ngầm định của toán tử lỏng lẻo (==): Sử dụng == có thể dẫn đến kết quả sai lệch ngoài ý muốn như 0 == "" (true) hoặc false == "0" (true), dễ gây ra lỗ hổng khi kiểm tra mã giảm giá hoặc số lượng sản phẩm.

Trực quan: So sánh Strict (===) Đơn hàng

script.js
LIVE PREVIEW 
// --- Bước 1: Tiếp nhận dữ liệu giỏ hàng từ form và hệ thống --- 
let rawInput = String(inputQty); // Dữ liệu từ HTML Input luôn là String
let stockQty = Number(targetQty); // Số lượng điều kiện/tồn kho dạng Number

// --- Bước 2: So sánh nghiêm ngặt (===) và khác nghiêm ngặt (!==) ---
let isDirectMatch = (rawInput === stockQty); // false vì String !== Number
let isStrictNotEqual = (rawInput !== stockQty); // true vì khác kiểu dữ liệu

// --- Bước 3: Chuyển đổi kiểu dữ liệu chuẩn hóa & Xác nhận thanh toán ---
let parsedInput = Number(rawInput);
let canProceedCheckout = (parsedInput === stockQty) && (parsedInput > 0);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Khai báo rawInput = "2" (kiểu String từ DOM) và stockQty = 2 (kiểu Number từ kho).
> 2. Bước 2: Thao tác "2" === 2 trả về false do lệch kiểu; "2" !== 2 trả về true.
> 3. Bước 3: Ép kiểu parsedInput = 2. So sánh 2 === 2 và 2 > 0 trả về true -> Cho phép thanh toán.
Kết quả đánh giá canProceedCheckout: true (Hợp lệ sau khi chuẩn hóa kiểu)

3. Toán tử Logic and (&&), or (||), not (!) và Ngắn mạch

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Toán tử Logic bao gồm AND (&&), OR (||) và NOT (!): dùng để kết hợp và đảo ngược các điều kiện logic trong biểu thức.
  • Cơ chế Ngắn mạch (Short-circuit Evaluation): biểu thức dừng đánh giá ngay khi kết quả được xác định — `&&` dừng khi gặp giá trị Falsy đầu tiên, `||` dừng khi gặp giá trị Truthy đầu tiên.
  • Ứng dụng thực tế: Thiết lập giá trị mặc định (dùng `||`), kiểm tra điều kiện an toàn trước khi thực thi (dùng `&&`) và kiểm tra trạng thái phủ định (dùng `!`).

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy Falsy với toán tử `||`: Khi viết `value || defaultValue`, nếu `value` chứa giá trị hợp lệ là `0` hoặc `""` (chuỗi rỗng), JS vẫn coi là Falsy và lấy `defaultValue` ngoài ý muốn (ví dụ: phí ship 0 VNĐ bị biến thành 30.000 VNĐ).

Bẫy thứ tự ưu tiên toán tử: Toán tử `&&` có độ ưu tiên cao hơn `||`. Biểu thức `A || B && C` sẽ được tính là `A || (B && C)`, có thể gây sai logic kiểm tra nếu không đóng bọc ngoặc đơn `()` rõ ràng.

Trực quan: Điều kiện Freeship & Short-Circuit

script.js
LIVE PREVIEW 
// --- Bước 1: Kiểm tra điều kiện Freeship (Toán tử &&, ||) ---
// Đơn hàng >= 300k HOẶC (Là khách VIP VÀ Đơn hàng >= 150k)
const isEligibleFreeship = cartTotal >= 300000 || (isVipMember === 1 && cartTotal >= 150000);

// --- Bước 2: Xử lý phí vận chuyển & bẫy ngắn mạch (||) ---
// Nếu không được Freeship, lấy phí nhập vào hoặc mặc định 30000 VNĐ
const finalShippingFee = isEligibleFreeship ? 0 : (customShippingFee || 30000);

// --- Bước 3: Đánh giá điều kiện cho phép Thanh toán (Toán tử !) ---
const isCartEmpty = cartTotal <= 0;
const canCheckout = !isCartEmpty && (isEligibleFreeship || finalShippingFee > 0);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Đánh giá 200000 >= 300000 (false) || (1 === 1 && 200000 >= 150000 -> true) => isEligibleFreeship = true.
> 2. Bước 2: Do đủ điều kiện Freeship (isEligibleFreeship = true), finalShippingFee = 0 VNĐ.
> 3. Bước 3: Đánh giá !isCartEmpty (true) && true => canCheckout = true (Đủ điều kiện thanh toán).
Kết quả đánh giá Freeship VIP: 0 VNĐ - Đủ điều kiện thanh toán
