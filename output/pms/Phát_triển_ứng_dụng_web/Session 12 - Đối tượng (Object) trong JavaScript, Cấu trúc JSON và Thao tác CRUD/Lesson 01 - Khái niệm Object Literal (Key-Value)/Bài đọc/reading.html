Khái niệm Object Literal (Key-Value)

1. Tại sao cần dùng Object Literal trong Quản lý Sản phẩm E-commerce?

Hãy tưởng tượng bạn đang xây dựng một ứng dụng bán hàng trực tuyến như Shopee hoặc Lazada. Mỗi sản phẩm trong hệ thống không chỉ đơn thuần là một giá trị riêng lẻ, mà chứa rất nhiều thuộc tính liên quan chặt chẽ với nhau: mã sản phẩm (ID), tên hàng, giá niêm yết, số lượng tồn kho và trạng thái khuyến mãi.

Nếu chúng ta lưu trữ từng thông tin này bằng các biến đơn lẻ độc lập như productName, productPrice, productStock, chương trình sẽ cực kỳ hỗn loạn khi danh sách sản phẩm tăng lên hàng ngàn mặt hàng. Việc truyền thông tin sản phẩm vào các hàm tính toán phí giao hàng hay áp mã giảm giá sẽ trở nên cồng kềnh, dễ nhầm lẫn dữ liệu giữa các sản phẩm với nhau.

Làm sao để gom tất cả thông tin của cùng một sản phẩm vào một đại diện duy nhất trong mã nguồn? Đó là lý do chúng ta cần sử dụng cấu trúc dữ liệu Object Literal với các cặp khóa - giá trị (Key-Value) trong JavaScript.

Hình 1.1: Sơ đồ bối cảnh thực tế bài học: Khái niệm Object Literal (Key-Value)

2. Cú pháp và Cơ chế hoạt động của Object Literal trong JavaScript

2.1. Cấu trúc Object Literal và cặp Key-Value

Object Literal trong JavaScript là một tập hợp các cặp khóa (key) và giá trị (value) được bao bọc trong cặp dấu ngoặc nhọn {}. Mỗi khóa đóng vai trò như một nhãn định danh cho một thuộc tính của đối tượng.

const objectName = {
  key1: value1,
  key2: value2,
  "key-3": value3
};
KẾT QUẢ THỰC THI (CONSOLE OUTPUT): 

  


  • Khóa (Key): Là một chuỗi ký tự (String) hoặc Symbol đóng vai trò định danh thuộc tính. Nếu tên khóa tuân thủ quy tắc đặt tên biến chuẩn trong JavaScript, ta có thể viết trực tiếp mà không cần dấu ngoặc kép.
  • Giá trị (Value): Có thể nhận bất kỳ kiểu dữ liệu hợp lệ nào trong JavaScript như Chuỗi (String), Số (Number), Booleans, Array, Function hoặc một Object khác.
  • Dấu phân cách: Các cặp Key-Value được phân tách nhau bởi dấu phẩy ,. Dấu phẩy ở cặp cuối cùng (trailing comma) là tùy chọn trong tiêu chuẩn ES6.
 Yêu cầu bài toán:
Khai báo đối tượng dữ liệu sản phẩm trong ứng dụng e-commerce chứa mã sản phẩm, tên, giá bán và trạng thái tồn kho.

  

    

      
      
      
    

    
// Khai báo đối tượng thông tin sản phẩm bằng Object Literal
const productInfo = {
  productId: "PRD-10293",
  productName: "Tai nghe Bluetooth Wireless X",
  originalPrice: 1500000,
  inStock: true
};

console.log("Đã khởi tạo đối tượng sản phẩm:", productInfo);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


2.2. Truy cập thuộc tính bằng Dot Notation (.)
Cú pháp dấu chấm (Dot Notation) là phương pháp truy cập thuộc tính phổ biến và trực quan nhất trong JavaScript. Cú pháp này được sử dụng khi bạn đã biết chính xác tên thuộc tính và tên khóa tuân thủ quy tắc đặt tên biến chuẩn.

  

    

      
      
      
    

    
const propertyValue = objectName.propertyName;

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


  • objectName: Tên biến đại diện cho đối tượng cần đọc dữ liệu.
  • propertyName: Tên khóa chính xác của thuộc tính muốn truy cập (không đặt trong dấu ngoặc báo chuỗi).
 Yêu cầu bài toán:
Đọc và hiển thị tên sản phẩm cùng giá bán từ đối tượng productInfo ra màn hình điều khiển.

  

    

      
      
      
    

    
const productInfo = {
  productId: "PRD-10293",
  productName: "Tai nghe Bluetooth Wireless X",
  price: 1500000
};

// Truy cập thuộc tính bằng Dot Notation
console.log("Tên sản phẩm:", productInfo.productName);
console.log("Giá bán:", productInfo.price);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


2.3. Truy cập thuộc tính bằng Bracket Notation ([])
Cú pháp ngoặc vuông (Bracket Notation) cho phép truy cập giá trị của thuộc tính bằng cách truyền một chuỗi biểu diễn tên khóa vào trong cặp ngoặc vuông []. Đây là cú pháp bắt buộc khi tên khóa chứa ký tự đặc biệt, khoảng trắng, bắt đầu bằng chữ số hoặc khi tên khóa được truyền dưới dạng biến số động.

  

    

      
      
      
    

    
const propertyValue = objectName["property-name"];
const dynamicValue = objectName[variableName];

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


  • Khai báo chuỗi trực tiếp: Đặt tên khóa trong dấu ngoặc kép hoặc ngoặc đơn objectName["product-code"]. Dùng cho các khóa có ký tự gạch ngang hay khoảng trắng.
  • Truy cập động qua biến: Truyền trực tiếp tên biến chứa chuỗi tên khóa objectName[targetField] (không có dấu ngoặc bao quanh tên biến).
 Yêu cầu bài toán:
Truy cập các thuộc tính có tên chứa ký tự đặc biệt như product-code và thuộc tính động theo giá trị của một biến người dùng chọn.

  

    

      
      
      
    

    
const productInfo = {
  "product-code": "PRD-10293",
  "shipping fee": 30000,
  price: 1500000
};

// 1. Truy cập khóa có ký tự đặc biệt hoặc khoảng trắng
console.log("Mã sản phẩm:", productInfo["product-code"]);

// 2. Truy cập thuộc tính thông qua tên biến động
const targetField = "shipping fee";
console.log("Phí vận chuyển:", productInfo[targetField]);

            3. Các ví dụ ứng dụng thực tiễn
          


          

            
3.1. Ví dụ 3.1: Khai báo và truy cập dữ liệu sản phẩm cơ bản
Ví dụ cơ bản khởi tạo một đối tượng sản phẩm máy tính xách tay với các thuộc tính định danh đơn giản và truy cập bằng Dot Notation.
 Yêu cầu bài toán:
Khai báo đối tượng sản phẩm laptop với các thuộc tính định danh và giá trị cơ bản, sau đó in các thông tin này ra màn hình console bằng Dot Notation.

  

    

      
      
      
    

    
// Khai báo đối tượng sản phẩm laptop
const laptopProduct = {
  id: "LAPTOP-PRO-16",
  name: "Laptop Pro 16 inch",
  brand: "TechBrand",
  price: 32000000,
  isAvailable: true
};

// Truy cập các thuộc tính bằng Dot Notation
console.log("--- THÔNG TIN SẢN PHẨM ---");
console.log("Mã sản phẩm:", laptopProduct.id);
console.log("Tên sản phẩm:", laptopProduct.name);
console.log("Thương hiệu:", laptopProduct.brand);
console.log("Giá niêm yết:", laptopProduct.price);
console.log("Trạng thái còn hàng:", laptopProduct.isAvailable);

3.2. Ví dụ 3.2: Truy cập thuộc tính có ký tự đặc biệt và sử dụng biến động
Ví dụ minh họa cách đọc các thuộc tính chứa ký tự gạch ngang, khoảng trắng và đọc dữ liệu động thông qua tên biến người dùng chỉ định.
 Yêu cầu bài toán:
Mở rộng đối tượng sản phẩm nhập khẩu với các thuộc tính chứa ký tự đặc biệt (gạch ngang, khoảng trắng) và thực hành truy cập thông qua tên biến dynamic.

  

    

      
      
      
    

    
// Khai báo sản phẩm nhập khẩu có các thuộc tính đặc thù
const importedProduct = {
  id: "IMP-8892",
  "product-sku-code": "SKU-VN-2026-X",
  "import tax percentage": 10,
  price: 25000000
};

// 1. Truy cập thuộc tính chứa ký tự đặc biệt bằng Bracket Notation
console.log("Mã SKU:", importedProduct["product-sku-code"]);
console.log("Thuế nhập khẩu (%):", importedProduct["import tax percentage"]);

// 2. Truy cập thuộc tính động thông qua một biến chứa tên khóa
const queryKey = "import tax percentage";
console.log("Giá trị truy vấn động cho '" + queryKey + "':", importedProduct[queryKey]);

3.3. Ví dụ 3.3: Hàm truy vấn thuộc tính sản phẩm an toàn cho hệ thống
Ví dụ thực tế trong hệ thống thương mại điện tử: Xây dựng hàm trợ giúp giúp kiểm tra và lấy thông tin bất kỳ thuộc tính nào của sản phẩm một cách an toàn mà không làm sập ứng dụng nếu thuộc tính đó chưa được định nghĩa.
 Yêu cầu bài toán:
Viết một hàm nhận vào đối tượng sản phẩm và tên thuộc tính cần đọc, trả về giá trị thuộc tính tương ứng hoặc thông báo cảnh báo an toàn nếu thuộc tính đó chưa được định nghĩa (undefined).

  

    

      
      
      
    

    
// Đối tượng dữ liệu sản phẩm chi tiết trong hệ thống
const detailProduct = {
  id: "PHONE-FLAGSHIP-01",
  name: "Điện thoại Flagship Ultra",
  price: 29990000,
  "warranty-period": "24 tháng",
  "warehouse-location": "Kho A - Tầng 2"
};

// Hàm truy cập thuộc tính an toàn dùng Bracket Notation
function getProductAttribute(product, attributeKey) {
  const attributeValue = product[attributeKey];

  // Kiểm tra nếu thuộc tính không tồn tại trong đối tượng
  if (attributeValue === undefined) {
    return "[WARNING] Thuộc tính '" + attributeKey + "' không tồn tại trên sản phẩm.";
  }

  return attributeValue;
}

// Kiểm tra với các thuộc tính hợp lệ
console.log("Thời gian bảo hành:", getProductAttribute(detailProduct, "warranty-period"));
console.log("Vị trí kho:", getProductAttribute(detailProduct, "warehouse-location"));

// Kiểm tra trường hợp thuộc tính không tồn tại
console.log("Mô tả sản phẩm:", getProductAttribute(detailProduct, "description"));

            4. Tổng kết bài học & Các lỗi thường gặp
          


          

            
4.1. Kiến thức trọng tâm
  • Object Literal cho phép gom nhóm nhiều thuộc tính liên quan của một đối tượng thực tế vào một biến duy nhất dưới dạng cặp Key-Value.
  • Sử dụng Dot Notation (object.key) khi khóa tuân theo chuẩn tên biến và đã biết trước cố định.
  • Sử dụng Bracket Notation (object["key"]) khi tên khóa chứa ký tự đặc biệt, khoảng trắng, số hoặc khi tên khóa nằm trong một biến số động.
  • Truy cập một thuộc tính không tồn tại trên Object sẽ trả về giá trị undefined thay vì báo lỗi dừng chương trình.
4.2. Bảng Ma trận Quyết định (Decision Matrix)

4.3. Các lỗi thường gặp & Lưu ý thực tế
 Lỗi 1: Cú pháp Dot Notation với tên khóa chứa ký tự đặc biệt
Cú pháp Dot Notation (.) chỉ hợp lệ khi tên khóa tuân đúng quy tắc đặt tên biến (không có khoảng trắng, dấu gạch ngang hoặc bắt đầu bằng số). Sử dụng Dot Notation với các tên khóa này sẽ gây ra lỗi SyntaxError.

  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  "product-id": "PRD-01"
};

// LỖI: SyntaxError: Unexpected token '-'
console.log(product.product-id);



  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  "product-id": "PRD-01"
};

// ĐÚNG: Sử dụng Bracket Notation cho tên khóa có dấu gạch ngang
console.log(product["product-id"]);


 Lỗi 2: Nhầm lẫn giữa tên biến và chuỗi ký tự trong Bracket Notation
Khi truyền một từ vào trong cặp ngoặc vuông [] mà không có dấu báo chuỗi (báo bằng "" hoặc ''), JavaScript sẽ coi đó là tên một biến. Nếu biến đó chưa được khai báo, chương trình sẽ báo lỗi ReferenceError.

  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  price: 500000
};

// LỖI: ReferenceError: price is not defined
console.log(product[price]);



  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  price: 500000
};

// ĐÚNG: Đặt tên khóa trong dấu ngoặc báo chuỗi
console.log(product["price"]);

// HOẶC ĐÚNG: Khai báo biến chứa chuỗi tên khóa trước khi truyền vào
const priceKey = "price";
console.log(product[priceKey]);


 Lỗi 3: Gọi phương thức hoặc thuộc tính con trên giá trị undefined
Truy cập một thuộc tính không tồn tại trên Object sẽ trả về undefined. Nếu tiếp tục truy cập thuộc tính con hoặc gọi phương thức trên giá trị undefined đó, chương trình sẽ phát sinh lỗi TypeError làm dừng ứng dụng.

  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  name: "Áo sơ mi"
};

// LỖI: TypeError: Cannot read properties of undefined (reading 'toUpperCase')
console.log(product.category.toUpperCase());



  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const product = {
  name: "Áo sơ mi"
};

// ĐÚNG: Kiểm tra thuộc tính tồn tại trước khi thao tác
if (product.category !== undefined) {
  console.log(product.category.toUpperCase());
} else {
  console.log("[NOTE] Thuộc tính 'category' không tồn tại.");
}
