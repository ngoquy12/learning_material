Thao tác Thêm, Sửa, Xóa Thuộc tính Object và Cấu trúc JSON

1. Tại sao ứng dụng E-commerce cần thay đổi đối tượng và chuyển đổi dữ liệu JSON linh hoạt?

Hãy tưởng tượng bạn đang xây dựng giao diện thanh toán cho một ứng dụng mua sắm trực tuyến. Khi người dùng bắt đầu duyệt sản phẩm, một đơn hàng mới được tạo ra dưới dạng đối tượng JavaScript. Trong suốt quá trình thao tác, dữ liệu đơn hàng liên tục biến động: khách hàng cập nhật địa chỉ nhận hàng, chọn phương thức thanh toán Momo hoặc COD, nhập mã giảm giá, hoặc bỏ chọn một mặt hàng khỏi giỏ.

Nếu cấu trúc đối tượng trong lập trình bị đóng cứng và không cho phép chỉnh sửa, hệ thống sẽ không thể ghi nhận các thay đổi thời gian thực này. Mặt khác, trước khi gửi đơn hàng lên Server để xử lý thanh toán hoặc lưu vào bộ nhớ trình duyệt (LocalStorage), đối tượng JavaScript sống đang tồn tại trong bộ nhớ RAM không thể truyền trực tiếp qua môi trường mạng Internet. Nếu không loại bỏ các thuộc tính tạm thời như ghi chú nội bộ hay mã token nháp, dữ liệu gửi đi sẽ bị thừa thãi và có nguy cơ rò rỉ thông tin bảo mật.

Để giải quyết bài toán này, JavaScript cung cấp cơ chế linh hoạt cho phép thêm mới, cập nhật giá trị và xóa bỏ hoàn toàn thuộc tính của Object. Đồng thời, chuẩn dữ liệu JSON (`JSON.stringify` và `JSON.parse`) đóng vai trò làm cầu nối biến đổi đối tượng thành dạng chuỗi văn bản an toàn, giúp hệ thống E-commerce lưu trữ và trao đổi dữ liệu mượt mà giữa Client và Server.

2. Cú pháp thao tác thuộc tính Object và Cấu trúc dữ liệu JSON trong JavaScript

2.1. Thêm và Sửa thuộc tính của Object (Add & Update Properties)

Trong JavaScript, đối tượng (Object) có tính chất động (dynamic). Bạn có thể dễ dàng thêm thuộc tính mới hoặc cập nhật giá trị của thuộc tính đã tồn tại thông qua hai cú pháp phổ biến: Dot Notation (dấu chấm) và Bracket Notation (ngặc vuông).

  • Dot Notation (`object.key = value`): Cú pháp ngắn gọn, dễ đọc, phù hợp khi tên thuộc tính là một định danh hợp lệ (không chứa khoảng trắng hoặc ký tự đặc biệt).
  • Bracket Notation (`object['key'] = value`): Sử dụng chuỗi làm tên thuộc tính. Bắt buộc dùng khi tên thuộc tính nằm trong biến số hoặc chứa ký tự đặc biệt.
  • Cơ chế hoạt động: Nếu tên thuộc tính chưa tồn tại trong đối tượng, JavaScript sẽ tự động khởi tạo cặp key-value mới. Nếu tên thuộc tính đã tồn tại, giá trị cũ sẽ bị đè lên bởi giá trị mới.

Yêu cầu bài toán:

Khởi tạo đối tượng đơn hàng cơ bản, sau đó bổ sung thông tin địa chỉ giao hàng, phương thức thanh toán và cập nhật tổng tiền sau khi áp dụng giảm giá.

// Khởi tạo đối tượng đơn hàng ban đầu
const order = {
  orderId: "ORD-10293",
  customerName: "Nguyen Van A",
  totalAmount: 500000
};

// 1. Thêm thuộc tính mới bằng Dot Notation và Bracket Notation
order.shippingAddress = "123 Đường Lê Lợi, Quận 1, TP.HCM";
order["paymentMethod"] = "COD";

// 2. Cập nhật giá trị thuộc tính đã tồn tại (áp dụng giảm giá 50.000 VNĐ)
order.totalAmount = 450000;

console.log("[INFO] Đơn hàng sau khi bổ sung và cập nhật:", order);
KẾT QUẢ THỰC THI (CONSOLE OUTPUT): 

  


  • Biến order lưu trữ đối tượng đơn hàng ban đầu với 3 thuộc tính: orderId, customerName, totalAmount.
  • Lệnh order.shippingAddress thêm thuộc tính địa chỉ giao hàng vào đối tượng.
  • Lệnh order["paymentMethod"] thêm phương thức thanh toán vào đối tượng.
  • Lệnh order.totalAmount = 450000 đè giá trị mới lên giá trị cũ 500000.
2.2. Xóa thuộc tính với toán tử delete (Delete Properties)
Khi xử lý đơn hàng, có những thông tin chỉ mang tính chất tạm thời (như mã giảm giá nháp, cờ kiểm thử, ghi chú nội bộ). Trước khi lưu hoặc hiển thị cho người dùng, chúng ta cần xóa hoàn toàn các thuộc tính này khỏi đối tượng bằng toán tử delete.
  • Cú pháp: delete object.key hoặc delete object['key'].
  • Kết quả thực thi: Toán tử loại bỏ hoàn toàn cả khóa (key) lẫn giá trị (value) ra khỏi bộ nhớ của đối tượng. Khi truy cập vào thuộc tính đã bị xóa, JavaScript sẽ trả về undefined.
  • Trả về boolean: Lệnh delete trả về true nếu xóa thành công thuộc tính khỏi đối tượng.
 Yêu cầu bài toán:
Loại bỏ thuộc tính mã giảm giá tạm thời khỏi đối tượng đơn hàng sau khi đã hoàn tất tính toán tổng tiền thanh toán.

  

    

      
      
      
    

    
// Khởi tạo đơn hàng chứa thông tin giảm giá tạm thời
const order = {
  orderId: "ORD-10293",
  totalAmount: 450000,
  tempCouponCode: "SUMMER2024"
};

// Xóa hoàn toàn thuộc tính tempCouponCode khỏi đối tượng
delete order.tempCouponCode;

// Kiểm tra kết quả truy cập thuộc tính sau khi xóa
console.log("[INFO] Giá trị tempCouponCode sau khi xóa:", order.tempCouponCode);
console.log("[INFO] Đối tượng đơn hàng hoàn chỉnh:", order);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


  • Khóa tempCouponCode ban đầu chứa giá trị chuỗi "SUMMER2024".
  • Lệnh delete order.tempCouponCode gỡ bỏ hoàn toàn cặp key-value này ra khỏi order.
  • Truy cập order.tempCouponCode sau khi xóa trả về kết quả undefined.
2.3. Chuyển đổi dữ liệu với JSON.stringify() và JSON.parse()
JSON (JavaScript Object Notation) là một định dạng văn bản nhẹ dùng để trao đổi dữ liệu giữa các hệ thống. Trong JavaScript, chúng ta sử dụng hai phương thức toàn cục để chuyển đổi qua lại giữa đối tượng và chuỗi JSON.
  • JSON.stringify(object): Chuyển đổi một đối tượng JavaScript thành chuỗi định dạng JSON để truyền qua mạng hoặc lưu vào Web Storage. Trong chuỗi JSON chuẩn, tất cả các khóa (key) và giá trị kiểu chuỗi đều bắt buộc bọc trong dấu ngoặc kép đôi (").
  • JSON.parse(jsonString): Chuyển đổi một chuỗi JSON hợp lệ ngược trở lại thành đối tượng JavaScript để chương trình có thể thao tác với các thuộc tính.
 Yêu cầu bài toán:
Chuyển đổi đối tượng đơn hàng thành chuỗi JSON để gửi API, sau đó giả định nhận lại chuỗi JSON từ Server và giải mã thành đối tượng JavaScript.

  

    

      
      
      
    

    
const order = {
  orderId: "ORD-10293",
  totalAmount: 450000,
  isPaid: true
};

// 1. Chuyển đối tượng thành chuỗi JSON chuẩn
const jsonString = JSON.stringify(order);
console.log("[INFO] Kiểu dữ liệu sau stringify:", typeof jsonString);
console.log("[INFO] Nội dung chuỗi JSON:", jsonString);

// 2. Giải mã chuỗi JSON ngược lại thành đối tượng JavaScript
const parsedOrder = JSON.parse(jsonString);
console.log("[INFO] Đã khôi phục đối tượng với mã đơn:", parsedOrder.orderId);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


  • Hàm JSON.stringify(order) chuyển đổi đối tượng thành dạng chuỗi '{"orderId":"ORD-10293","totalAmount":450000,"isPaid":true}'.
  • Hàm JSON.parse(jsonString) khôi phục chuỗi trên thành đối tượng JavaScript thực thụ.
  • Thuộc tính parsedOrder.orderId có thể được truy cập bình thường sau khi giải mã.

            3. Các ví dụ ứng dụng thực tiễn
          


          

            
3.1. Ví dụ 3.1: Thao tác cơ bản Thêm, Sửa, Xóa thuộc tính đơn hàng
Ví dụ này minh họa các thao tác cơ bản nhất khi cập nhật thông tin đơn hàng trong giỏ hàng: thêm phương thức thanh toán, tính toán phí vận chuyển và xóa bỏ thông tin nhạy cảm nội bộ.
 Yêu cầu bài toán:
Khởi tạo đối tượng đơn hàng với ghi chú nội bộ, thực hiện bổ sung phương thức thanh toán, cộng phí vận chuyển vào tổng tiền và xóa ghi chú nội bộ trước khi hiển thị cho khách hàng.

  

    

      
      
      
    

    
// Khởi tạo đơn hàng cơ bản
const ecommerceOrder = {
  orderId: "ORD-8821",
  customerName: "Tran Thi B",
  subtotal: 1200000,
  internalNote: "Khách hàng ưu tiên giao buổi sáng"
};

// 1. Thêm thuộc tính phương thức thanh toán và phí vận chuyển
ecommerceOrder.paymentMethod = "Momo";
ecommerceOrder.shippingFee = 30000;

// 2. Sửa (Cập nhật) tổng tiền bao gồm cả phí vận chuyển
ecommerceOrder.totalAmount = ecommerceOrder.subtotal + ecommerceOrder.shippingFee;

// 3. Xóa thuộc tính ghi chú nội bộ bảo mật
delete ecommerceOrder.internalNote;

// Hiển thị kết quả đơn hàng đã được cập nhật
console.log("[INFO] Đơn hàng sau khi dọn dẹp và cập nhật:", ecommerceOrder);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


Chương trình thực hiện 3 bước thao tác dữ liệu cơ bản:
  • Khởi tạo đối tượng ecommerceOrder với 4 thuộc tính cơ bản.
  • Thêm thuộc tính paymentMethod và shippingFee vào đối tượng.
  • Cập nhật thuộc tính totalAmount bằng tổng giá trị hàng subtotal và phí ship shippingFee (1.230.000 VNĐ).
  • Sử dụng toán tử delete loại bỏ hoàn toàn thuộc tính internalNote.
3.2. Ví dụ 3.2: Lưu trữ và Khôi phục đơn hàng với JSON
Ví dụ này thể hiện quy trình đóng gói đối tượng đơn hàng thành chuỗi JSON để giả định gửi lên Server, sau đó giải mã chuỗi nhận về để cập nhật trạng thái đơn hàng.
 Yêu cầu bài toán:
Chuyển đổi đối tượng đơn hàng từ Ví dụ 3.1 thành chuỗi JSON chuẩn. Đọc lại chuỗi JSON này, giải mã thành đối tượng JavaScript và cập nhật trạng thái đơn hàng thành CONFIRMED.

  

    

      
      
      
    

    
const orderData = {
  orderId: "ORD-8821",
  customerName: "Tran Thi B",
  totalAmount: 1230000,
  status: "PENDING"
};

// Bước 1: Mã hóa đối tượng đơn hàng thành chuỗi JSON để gửi/lưu trữ
const serializedOrder = JSON.stringify(orderData);
console.log("[INFO] Chuỗi JSON chuẩn bị gửi lên Server:");
console.log(serializedOrder);

// Bước 2: Mô phỏng nhận chuỗi JSON từ Server/Storage và giải mã thành JS Object
const deserializedOrder = JSON.parse(serializedOrder);

// Bước 3: Đổi trạng thái đơn hàng trên đối tượng vừa khôi phục
deserializedOrder.status = "CONFIRMED";
deserializedOrder.confirmedAt = "2024-10-24 14:30:00";

console.log("[INFO] Đơn hàng sau khi khôi phục từ JSON và cập nhật trạng thái:", deserializedOrder);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


Đoạn mã mã hóa đối tượng orderData thành chuỗi JSON thông qua JSON.stringify(), sau đó tái tạo lại đối tượng JavaScript độc lập bằng JSON.parse() và tiến hành cập nhật trạng thái status.
3.3. Ví dụ 3.3: Xử lý dữ liệu đơn hàng hoàn chỉnh và đóng gói an toàn
Trong thực tế phát triển phần mềm, dữ liệu nhận từ giao diện người dùng có thể bị lỗi hoặc chứa các trường thông tin rác. Ví dụ này xây dựng hàm đóng gói và giải mã dữ liệu an toàn với khối lệnh try...catch.
 Yêu cầu bài toán:
Viết hàm chuẩn hóa đơn hàng thô: bổ sung thời gian cập nhật, xóa token tạm thời, mã hóa JSON và xử lý ngoại lệ an toàn khi giải mã các chuỗi JSON không đúng định dạng.

  

    

      
      
      
    

    
/**
 * Hàm chuẩn hóa và đóng gói dữ liệu đơn hàng gửi lên hệ thống trung tâm
 * @param {Object} rawOrderData - Dữ liệu đơn hàng thô từ giao diện
 * @returns {string|null} Chuỗi JSON hợp lệ hoặc null nếu có lỗi
 */
function prepareOrderPayload(rawOrderData) {
  try {
    // Đảm bảo tham số truyền vào là một object hợp lệ
    if (!rawOrderData || typeof rawOrderData !== "object") {
      throw new Error("Dữ liệu đơn hàng đầu vào không hợp lệ.");
    }

    // 1. Tạo bản sao để tránh thay đổi trực tiếp dữ liệu gốc (Immutability pattern)
    const processedOrder = { ...rawOrderData };

    // 2. Thêm thuộc tính hệ thống
    processedOrder.updatedAt = new Date().toISOString();
    processedOrder.platform = "WEB_APP";

    // 3. Cập nhật trạng thái nghiệp vụ
    processedOrder.status = "PROCESSING";

    // 4. Xóa thuộc tính mã bảo mật tạm thời và cờ kiểm thử nội bộ
    delete processedOrder.draftToken;
    delete processedOrder.isTestOrder;

    // 5. Chuyển đổi sang JSON String
    const jsonPayload = JSON.stringify(processedOrder);
    return jsonPayload;
  } catch (error) {
    console.error("[ERROR] Rủi ro khi đóng gói đơn hàng:", error.message);
    return null;
  }
}

// Chạy thử nghiệm với dữ liệu đơn hàng thô từ client
const rawCart = {
  orderId: "ORD-9954",
  customerName: "Le Van C",
  itemsCount: 3,
  draftToken: "xyz-temp-token-123",
  isTestOrder: true
};

const finalPayload = prepareOrderPayload(rawCart);
console.log("[RESULT] Payload JSON sẵn sàng gửi đi API:", finalPayload);

// Chạy thử nghiệm trường hợp chuỗi JSON hỏng với JSON.parse an toàn
function safeParseOrderJson(jsonString) {
  try {
    return JSON.parse(jsonString);
  } catch (error) {
    console.warn("[WARNING] Lỗi định dạng JSON không hợp lệ:", error.message);
    return null;
  }
}

const corruptedJson = '{"orderId": "ORD-9954", "status": PROCESSING}'; // Thiếu dấu ngoặc kép ở PROCESSING
safeParseOrderJson(corruptedJson);

  

  

    

      
         KẾT QUẢ THỰC THI (CONSOLE OUTPUT):
      
    

    

  


Hàm prepareOrderPayload tự động bổ sung trường thời gian updatedAt, loại bỏ các trường tạm như draftToken và bọc toàn bộ thao tác trong khối try...catch để tránh làm treo ứng dụng khi gặp dữ liệu không hợp lệ.

4. Tổng kết bài học & Các lỗi thường gặp
4.1. Kiến thức trọng tâm
  • Đối tượng JavaScript có cấu trúc thuộc tính động, cho phép thêm và cập nhật giá trị linh hoạt bằng Dot Notation hoặc Bracket Notation.
  • Toán tử delete là cách duy nhất để xóa hoàn toàn một cặp key-value khỏi bộ nhớ của đối tượng.
  • Phương thức JSON.stringify() dùng để mã hóa đối tượng thành chuỗi JSON phục vụ truyền nhận qua mạng.
  • Phương thức JSON.parse() giải mã chuỗi JSON thành đối tượng JavaScript và bắt buộc phải đặt trong khối lệnh try...catch để phòng ngừa lỗi cú pháp.

4.3. Các lỗi thường gặp & Lưu ý thực tế
 Lỗi 1: Nhầm lẫn giữa gán giá trị undefined/null và dùng toán tử delete
Khi bạn gán order.tempCoupon = undefined hoặc null, thuộc tính đó vẫn tồn tại trong đối tượng và vẫn xuất hiện khi duyệt qua đối tượng bằng Object.keys(). Chỉ có toán tử delete mới xóa sạch thuộc tính đó.

  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const order = { orderId: "ORD-101", tempCoupon: "DISCOUNT10" };

// SAI: Gán undefined không thực sự xóa key khỏi object
order.tempCoupon = undefined;

console.log("tempCoupon" in order); // Kết quả: true (Vẫn tồn tại key!)
console.log(Object.keys(order)); // Kết quả: ["orderId", "tempCoupon"]



  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const order = { orderId: "ORD-101", tempCoupon: "DISCOUNT10" };

// ĐÚNG: Dùng toán tử delete để xóa triệt để thuộc tính
delete order.tempCoupon;

console.log("tempCoupon" in order); // Kết quả: false
console.log(Object.keys(order)); // Kết quả: ["orderId"]


 Lỗi 2: Lỗi parse chuỗi JSON sai định dạng cú pháp (SyntaxError)
Hàm JSON.parse() đòi hỏi chuỗi truyền vào phải tuân thủ nghiêm ngặt cú pháp JSON (dùng dấu ngoặc kép cho cả key và giá trị chuỗi, không thừa dấu phẩy). Nếu truyền vào chuỗi sai cú pháp mà không bọc trong try...catch, chương trình sẽ ngắt đột ngột.

  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const invalidJsonString = "{ 'orderId': 'ORD-101', }"; // Nháy đơn và thừa dấu phẩy cuối

// SAI: Gọi JSON.parse trực tiếp mà không bọc bắt lỗi
const orderData = JSON.parse(invalidJsonString); // Làm sập ứng dụng (SyntaxError)



  

    
      
      
      
      Cú pháp mẫu Javascript
    
    
  

  
const invalidJsonString = "{ 'orderId': 'ORD-101', }";

// ĐÚNG: Luôn bọc JSON.parse trong khối try...catch để xử lý an toàn
try {
  const orderData = JSON.parse(invalidJsonString);
  console.log(orderData);
} catch (error) {
  console.error("[WARNING] Không thể giải mã JSON do sai định dạng:", error.message);
}
