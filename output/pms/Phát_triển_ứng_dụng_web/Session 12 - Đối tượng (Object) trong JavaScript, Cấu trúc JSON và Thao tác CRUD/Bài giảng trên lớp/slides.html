1. Khái niệm Object Literal & Bản chất Vùng nhớ (Stack vs Heap)

Lesson 01

Cấu trúc Object Literal & Truy xuất

CÚ PHÁP

Object Literal là cấu trúc dữ liệu lưu trữ dưới dạng các cặp Key: Value, được khai báo thuận tiện bằng cặp ngoặc nhọn {}.

  • Dot Notation (obj.key): Dùng khi biết trước tên thuộc tính cố định hợp lệ (không chứa ký tự đặc biệt hay khoảng trắng).
  • Bracket Notation (obj[dynamicVar]): Bắt buộc khi tên key nằm trong biến động hoặc chứa ký tự đặc biệt (ví dụ: obj["ma-nhan-su"]).

Bản chất Vùng nhớ: Stack vs Heap

BỘ NHỚ RAM

Object trong JavaScript là Kiểu dữ liệu tham chiếu (Reference Type):

  • Call Stack: Chỉ lưu địa chỉ con trỏ vùng nhớ (Pointer Address, ví dụ: 0x7FFE01).
  • Memory Heap: Nơi thực sự lưu trữ toàn bộ Payload dữ liệu của Object.
  • Tại sao const vẫn sửa được thuộc tính? Vì const chỉ khóa địa chỉ con trỏ trên Stack không cho trỏ đi nơi khác; nội dung bên trong Heap vẫn có thể thay đổi linh hoạt.

Bẫy lỗi Tham chiếu (Mutation Bug)

LƯU Ý THỰC CHIẾN

Bẫy sao chép tham chiếu: Khi thực hiện let b = a, hai biến cùng trỏ vào 1 địa chỉ Heap. Mọi thay đổi qua b sẽ làm biến dạng dữ liệu của a!

So sánh đối tượng: {} === {} luôn trả về false vì JavaScript so sánh 2 địa chỉ vùng nhớ khác nhau, không so sánh nội dung bên trong.

2. Thao tác CRUD Thuộc tính, Nested Object & Đóng gói JSON

Lesson 02

Thao tác CRUD Thuộc tính & Delete

CRUD OBJECT
  • Create / Update: Gán giá trị mới qua dấu chấm hoặc ngoặc vuông (emp.bonus = 15; emp['role'] = 'Lead';).
  • Delete: Sử dụng toán tử delete emp.tempNote; để xóa triệt để cả Key lẫn Value khỏi Object.
  • Phân biệt: Gán emp.tempNote = null hoặc undefined chỉ đổi giá trị nhưng Key vẫn tồn tại trong Object!

Đối tượng Lồng nhau & Optional Chaining

NESTED OBJECT

Dữ liệu doanh nghiệp luôn có dạng cây phân cấp (Object chứa Object con hoặc Mảng):

emp.department?.manager?.email

Sử dụng Optional Chaining (?.) giúp truy xuất an toàn. Nếu department là undefined, biểu thức trả về undefined thay vì làm sụp đổ ứng dụng với lỗi TypeError: Cannot read properties of undefined.

Cấu trúc JSON & Bẫy Chuyển đổi

JSON chuẩn
  • JSON.stringify(obj): Chuyển Object thành chuỗi JSON để gửi qua HTTP Request. Lưu ý: Function và thuộc tính undefined sẽ bị bỏ qua; NaN và Infinity bị ép thành null.
  • JSON.parse(str): Giải mã chuỗi JSON thành Object. Key trong JSON bắt buộc phải có nháy kép "key". Luôn bọc JSON.parse trong khối try...catch để tránh SyntaxError.
