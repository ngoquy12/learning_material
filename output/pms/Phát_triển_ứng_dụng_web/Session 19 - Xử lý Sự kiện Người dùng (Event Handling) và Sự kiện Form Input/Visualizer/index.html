1. (Session 19 - Xử lý Sự kiện Người dùng (Event Handling) và Sự kiện Form Input):

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Sử dụng phương thức targetElement.addEventListener(eventName, listenerFunction) để đăng ký lắng nghe sự kiện trên đối tượng DOM.
  • Tên sự kiện (eventName) là chuỗi ký tự chuẩn dạng chữ thường (như 'click', 'input', 'submit'), tuyệt đối không chứa tiền tố 'on'.
  • Hàm listenerFunction (callback) tự động nhận đối tượng sự kiện (event object e) chứa thông tin chi tiết về hành vi tương tác của người dùng.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Nhầm lẫn truyền tiền tố 'on' vào addEventListener (ví dụ viết 'onclick' thay vì 'click'), khiến sự kiện không bao giờ được kích hoạt.

Quên ngăn chặn hành vi mặc định (e.preventDefault()) khi bắt sự kiện 'submit' trên Form, dẫn đến trang web tự động tải lại và làm mất toàn bộ dữ liệu.

Trực quan: Xử lý Sự kiện Nhập kho

script.js
LIVE PREVIEW 
// Bước 1: Truy xuất các phần tử DOM trong hệ thống kho hàng
const btnAddStock = document.querySelector('#btn-add-stock');
const inputProduct = document.querySelector('#product-name');
const inputQty = document.querySelector('#stock-qty');

// Bước 2: Đăng ký sự kiện 'click' bằng addEventListener
btnAddStock.addEventListener('click', function(event) {
  const nameValue = inputProduct.value.trim();
  const qtyValue = parseInt(inputQty.value, 10);

  // Bước 3: Kiểm tra dữ liệu và cập nhật danh mục sản phẩm
  if (!nameValue || isNaN(qtyValue) || qtyValue <= 0) {
    return 'Lỗi: Dữ liệu nhập kho không hợp lệ!';
  }
  return `Thành công: Đã thêm ${qtyValue} ${nameValue} vào kho`;
});

> 1. Bước 1: Truy xuất nút bấm `#btn-add-stock` và các ô nhập liệu từ DOM kho hàng.
> 2. Bước 2: Sự kiện 'click' kích hoạt hàm callback, đọc giá trị Tên = 'Áo khoác Nam' và Số lượng = 50.
> 3. Bước 3: Dữ liệu hợp lệ, hệ thống ghi nhận bổ sung thành công 50 sản phẩm vào kho.

2. Đăng ký Sự kiện với addEventListener

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Phương thức `targetElement.addEventListener(eventName, listenerFunction)` dùng để đăng ký lắng nghe sự kiện trên phần tử DOM (truy xuất qua `querySelector`) mà không làm ghi đè lên các trình xử lý sự kiện đã khai báo trước đó.
  • Tham số `eventName` nhận chuỗi tên sự kiện tiêu chuẩn (như `'click'`, tuyệt đối không có tiền tố `'on'`), kết hợp với hàm callback `listenerFunction` để tự động thực thi logic khi sự kiện phát sinh.
  • Khối lệnh rẽ nhánh `if-else` đặt bên trong hàm callback giúp kiểm tra điều kiện dữ liệu (như số lượng tồn kho) và thực thi thụt lề chuẩn trong khối `{}` để cập nhật trạng thái hệ thống.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy dùng tiền tố 'on': Viết `addEventListener('onclick', ...)` thay vì `'click'`. Trình duyệt sẽ không nhận diện được tên sự kiện và không kích hoạt hàm xử lý.

Bẫy thực thi hàm ngay lập tức: Viết `btn.addEventListener('click', updateStock())` thay vì truyền tên hàm `updateStock` hoặc arrow function `() => updateStock()`, khiến hàm chạy ngay khi nạp trang chứ không chờ người dùng nhấn nút.

Xử lý Sự kiện Click Cập nhật Tồn kho

script.js
LIVE PREVIEW 
// Bước 1: Truy xuất nút thao tác xuất kho từ giao diện DOM
const exportBtn = document.querySelector('#btn-export-product');

// Bước 2: Định nghĩa hàm callback kiểm tra và rẽ nhánh điều kiện tồn kho
function processExport(currentStock, exportQty) {
  if (exportQty <= 0) {
    return 'Lỗi: Số lượng xuất phải lớn hơn 0';
  } else if (exportQty > currentStock) {
    return 'Thất bại: Tồn kho không đủ đáp ứng';
  } else {
    const remaining = currentStock - exportQty;
    return `Thành công: Đã xuất ${exportQty} sản phẩm (Còn: ${remaining})`;
  }
}

// Bước 3: Đăng ký sự kiện 'click' chuẩn (không dùng tiền tố 'on')
exportBtn.addEventListener('click', function() {
  const result = processExport(currentStock, exportQty);
  console.log(result);
});
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Sự kiện 'click' bắt phần tử #btn-export-product và khởi chạy hàm callback xử lý xuất kho.
> 2. Bước 2: Khối `if-else` kiểm tra điều kiện: 15 > 0 (Đúng) và 15 > 50 (Sai), chuyển vào khối `else`.
> 3. Bước 3: Trừ tồn kho (50 - 15 = 35) và trả về thông báo cập nhật xuất kho thành công.

3. Làm việc với Form, Input và Sự kiện submit

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Lắng nghe sự kiện trên phần tử DOM bằng `addEventListener(eventName, listenerFunction)`: truyền tên sự kiện chuẩn (ví dụ: 'click', 'submit') không có tiền tố 'on'.
  • Bắt sự kiện submit form và sử dụng `event.preventDefault()` để ngăn chặn hành vi tự động tải lại trang của trình duyệt.
  • Kết hợp cú pháp rẽ nhánh `if-else` và khối lệnh `{}` để phân loại logic kiểm tra dữ liệu đầu vào (input value) trước khi lưu vào hệ thống kho.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Quên ép kiểu dữ liệu từ `input.value`: Thuộc tính `.value` luôn trả về chuỗi (`string`). Nếu không dùng `Number()` hoặc `parseInt()`, phép so sánh trong `if (qty > 50)` sẽ bị sai logic do so sánh chuỗi.

Thiếu `e.preventDefault()` trong sự kiện submit form: Trình duyệt sẽ reload trang ngay lập tức, làm mất toàn bộ trạng thái JavaScript và không kịp chạy khối lệnh kiểm tra dữ liệu.

Xử lý Form Nhập Kho Sản Phẩm

script.js
LIVE PREVIEW 
// Bước 1: Khai báo hàm xử lý kiểm tra sản phẩm nhập kho
function validateProductImport(qtyStr, priceStr) {
  // Bước 2: Ép kiểu dữ liệu đầu vào từ input của form
  const qty = Number(qtyStr);
  const price = Number(priceStr);

  // Bước 3: Rẽ nhánh điều kiện kiểm tra hạn mức và lưu kho
  if (isNaN(qty) || qty <= 0 || isNaN(price) || price <= 0) {
    return "Lỗi: Số lượng và giá phải là số dương hợp lệ!";
  } else if (qty >= 100) {
    const totalValue = qty * price;
    return `Nhập kho sỉ thành công! Tổng trị giá: ${totalValue.toLocaleString('vi-VN')} VNĐ (Ô kệ A1)`;
  } else {
    const totalValue = qty * price;
    return `Nhập kho lẻ thành công! Tổng trị giá: ${totalValue.toLocaleString('vi-VN')} VNĐ (Kệ B2)`;
  }
}
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Lấy dữ liệu chuỗi '150' và '200000' từ ô nhập liệu form sản phẩm.
> 2. Bước 2: Ép kiểu Number thành công (qty = 150, price = 200000). Kiểm tra điều kiện `qty >= 100` -> Đạt.
> 3. Bước 3: Kích hoạt khối `else if (qty >= 100)`, tính tổng tiền 30.000.000 VNĐ và gán vị trí Ô kệ A1.
