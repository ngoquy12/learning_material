1. (Session 14 - Tổ chức Hàm (Function), Tham số, Arrow Function và Phạm vi Scope):

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Hàm (`function`) đóng gói khối mã xử lý giao dịch thanh toán tái sử dụng, nhận các tham số (`parameters`) đại diện cho dữ liệu và trả về kết quả qua từ khóa `return`.
  • Tên hàm (`functionName`) tuân thủ quy chuẩn `camelCase` thể hiện rõ hành động (ví dụ: `calculatePaymentFee`), giúp mã nguồn tường minh và dễ bảo trì.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Cố gắng gọi biến chứa Function Expression trước dòng khai báo gán giá trị sẽ khiến chương trình dừng đột ngột với lỗi `ReferenceError` do tính chất TDZ.

Quên từ khóa `return` trong hàm xử lý sẽ khiến hàm mặc định trả về `undefined`, gây ra lỗi tính toán số tiền giao dịch sai lệch ở các bước tiếp theo.

Trực quan: Hàm Tính Phí Giao Dịch

script.js
LIVE PREVIEW 
// --- Bước 1: Khai báo hàm tính phí giao dịch (Function Declaration) ---
function calculatePaymentFee(amount, feeRate, fixedFee) {
  // Tính phí theo tỷ lệ phần trăm giao dịch
  const percentageFee = (amount * feeRate) / 100;
  
  // --- Bước 2: Tổng hợp phí cố định và phí tỷ lệ ---
  const totalFee = percentageFee + fixedFee;
  
  // --- Bước 3: Trả về kết quả tổng phí cổng thanh toán ---
  return totalFee;
}

// Gọi hàm với các thông số từ giao dịch hiện tại
const finalFee = calculatePaymentFee(amount, feeRate, fixedFee);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Nhận amount = 500,000 VNĐ, feeRate = 2%. Phí phần trăm = (500,000 * 2) / 100 = 10,000 VNĐ.
> 2. Bước 2: Cộng phí cố định fixedFee = 3,000 VNĐ. Tổng phí totalFee = 10,000 + 3,000 = 13,000 VNĐ.
> 3. Bước 3: Hàm return kết quả 13,000 VNĐ cho biến finalFee để khấu trừ giao dịch.
Kết quả đánh giá Phí giao dịch: 13,000 VNĐ

2. Khai báo Hàm (Function Declaration & Expression)

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Function Declaration (Khai báo hàm): Cú pháp `function name(param) {}`, có cơ chế Hoisting đầy đủ, cho phép thực thi trước vị trí khai báo trong mã nguồn.
  • Function Expression (Biểu thức hàm): Gán hàm ẩn danh vào một biến (`const name = function() {}`), tuân theo phạm vi khởi tạo của biến và không thể gọi trước khi gán.
  • Tham số & Từ khóa return: Tham số đóng vai trò nhận dữ liệu giao dịch đầu vào; từ khóa `return` trả về kết quả tính toán và lập tức dừng luồng thực thi của hàm.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Lỗi gọi trước khi khởi tạo với Function Expression: Gọi hàm định nghĩa dạng biểu thức trước dòng gán giá trị sẽ gây lỗi `ReferenceError: Cannot access before initialization` do Temporal Dead Zone (TDZ).

Quên từ khóa return: Nếu hàm xử lý giao dịch thiếu từ khóa `return`, kết quả mặc định trả về là `undefined`, dẫn đến các phép toán tổng tiền tiếp theo bị lỗi `NaN`.

Trực quan: Khai báo Hàm Thanh toán

script.js
LIVE PREVIEW 
// --- Bước 1: Function Declaration (Tính phí cổng thanh toán) --- 
function calculateGatewayFee(amount, feePct) {
  if (amount <= 0 || feePct < 0) return 0;
  return (amount * feePct) / 100;
}

// --- Bước 2: Function Expression (Tính tổng tiền thực thanh toán) ---
const calculateTotalPayment = function(amount, fee) {
  return amount + fee;
};

// --- Bước 3: Đánh giá kết quả & Trả về tổng giao dịch ---
const fee = calculateGatewayFee(amount, gateFeePct);
const totalPayment = calculateTotalPayment(amount, fee);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Thực thi Function Declaration `calculateGatewayFee(500000, 2)` -> Phí cổng tính được là 10,000 VNĐ.
> 2. Bước 2: Thực thi Function Expression `calculateTotalPayment(500000, 10000)` -> Tính tổng số tiền.
> 3. Bước 3: Trả về kết quả tổng thanh toán hoàn chỉnh: 510,000 VNĐ.
Kết quả đánh giá 510,000 VNĐ (Phí: 10,000 VNĐ)

3. Cú pháp Arrow Function ES6 và Tham số Mặc định

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Cú pháp Arrow Function (`() => {}`) giúp khai báo hàm ngắn gọn trong ES6, tự động kế thừa ngữ cảnh `this` từ phạm vi cha và không hỗ trợ cơ chế hoisting như `function` truyền thống.
  • Tham số mặc định (Default Parameters) cho phép gán sẵn giá trị khởi tạo cho biến đầu vào (ví dụ: `feeRate = 1.5`), giúp ngăn chặn lỗi `NaN` hoặc `undefined` khi gọi hàm thiếu đối số.
  • Lộ trình 30 buổi học: Định hướng phát triển từ tư duy logic ES6+, xử lý DOM, Fetch API đến việc xây dựng Demo sản phẩm tích hợp API thanh toán thực tế.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Bẫy Hoisting: Gọi Arrow Function trước dòng khai báo sẽ làm dừng chương trình với lỗi `Uncaught ReferenceError: Cannot access 'processPayment' before initialization`.

Bẫy Tham số Mặc định với `null`: Giá trị mặc định chỉ được kích hoạt khi truyền `undefined` hoặc bỏ trống. Truyền `null` sẽ khiến hàm nhận `null` (chuyển thành 0) thay vì giá trị mặc định.

Trực quan: Arrow Function & Tham Số Mặc Định

script.js
LIVE PREVIEW 
// --- Bước 1: Khai báo Arrow Function tính phí với Tham số Mặc định ---
const calculateGatewayFee = (amount, feeRate = 1.5) => {
  const actualRate = feeRate === undefined ? 1.5 : feeRate;
  return (amount * Number(actualRate)) / 100;
};

// --- Bước 2: Arrow Function tính Tổng tiền Giao dịch Đa cổng ---
const calculateTotalPayment = (amount, feeRate, discount = 0) => {
  const fee = calculateGatewayFee(amount, feeRate);
  return amount + fee - discount;
};

// --- Bước 3: Thực thi và Đánh giá Kết quả Thanh toán ---
const totalPayment = calculateTotalPayment(amount, feeRate, discount);
console.log(`[Payment Gateway] Tổng thanh toán: ${totalPayment} VNĐ`);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Arrow Function `calculateGatewayFee` nhận số tiền 500,000 VNĐ và phí cổng 2.5%, tính ra tiền phí là 12,500 VNĐ.
> 2. Bước 2: Hàm `calculateTotalPayment` gộp tiền gốc 500,000 VNĐ + 12,500 VNĐ phí cổng và trừ đi 20,000 VNĐ chiết khấu.
> 3. Bước 3: Tính toán thành công, kết quả tổng thanh toán cuối cùng là 492,500 VNĐ.
Kết quả đánh giá 492500 VNĐ

4. Phạm vi Biến Global, Local Scope và Closures cơ bản

Khái niệm & Cú pháp Cốt lõi

KHÁI NIỆM & CÚ PHÁP
  • Phạm vi biến (Scope) quy định vùng truy cập của biến: Biến Global tồn tại toàn cục, trong khi Local Scope (Block/Function scope với let/const) chỉ truy cập được bên trong hàm hoặc khối lệnh khai báo.
  • Closure là cơ chế cho phép một hàm con ghi nhớ và truy cập vào các biến thuộc Lexical Scope của hàm cha chứa nó, ngay cả khi hàm cha đã thực thi hoàn tất.
  • Ứng dụng Closure trong thực tế giúp đóng gói dữ liệu riêng tư (private state) như bộ đếm giao dịch, cấu hình phí cổng thanh toán mà không làm ô nhiễm scope toàn cục.

Lưu ý & Bẫy lỗi Thường gặp

LƯU Ý THỰC HÀNH

Rò rỉ biến Global (Accidental Global): Quên khai báo từ khóa let/const khi gán biến trong hàm sẽ vô tình biến nó thành biến Global, dễ gây xung đột dữ liệu giao dịch giữa các cổng.

Biến đổi trạng thái chia sẻ (Shared State Mutation): Các Closure tạo từ cùng một hàm cha nếu dùng chung biến ngoài dạng Object/Array có thể vô tình làm thay đổi dữ liệu của nhau ngoài dự kiến.

Trực quan: Closure Quản lý Phí Thanh toán

script.js
LIVE PREVIEW 
// --- Bước 1: Khai báo Global Scope & Định nghĩa Closure Khởi tạo Cổng --- 
const GLOBAL_CURRENCY = "VNĐ";

function createPaymentProcessor(gatewayName, feePercent) {
  // Local variable đóng vai trò Private State nhờ Closure
  let transactionCount = 0;

  return function processPayment(amount) {
    // Lexical Scope: Truy cập biến amount, feePercent, transactionCount & GLOBAL_CURRENCY
    if (!amount || amount <= 0) {
      return "Lỗi: Số tiền giao dịch không hợp lệ";
    }
    
    transactionCount++;
    const fee = (amount * feePercent) / 100;
    const totalAmount = amount + fee;
    
    return `[${gatewayName}] Giao dịch #${transactionCount}: Tổng ${totalAmount.toLocaleString()} ${GLOBAL_CURRENCY} (Phí: ${fee.toLocaleString()} ${GLOBAL_CURRENCY})`;
  };
}

// --- Bước 2: Tạo Trạm xử lý với Closure & Đóng gói Phí --- 
const amount = Number(param1);
const feePercent = Number(param2);

const vnpayProcessor = createPaymentProcessor("VNPAY", feePercent);

// --- Bước 3: Thực thi Thanh toán & Đánh giá Trạng thái Scope --- 
const result = vnpayProcessor(amount);
TIẾN TRÌNH THỰC THI (RUNTIME TRACE) REALTIME
> 1. Bước 1: Đọc hằng số Global GLOBAL_CURRENCY = 'VNĐ' và khởi tạo closure createPaymentProcessor cho cổng VNPAY.
> 2. Bước 2: Truyền số tiền 500,000 VNĐ và phí 2% vào hàm closure vnpayProcessor.
> 3. Bước 3: Hàm inner tăng biến đếm riêng transactionCount lên 1, tính tổng 510,000 VNĐ và trả về chuỗi kết quả.
Kết quả đánh giá [VNPAY] Giao dịch #1: Tổng 510,000 VNĐ (Phí: 10,000 VNĐ)
