Chỉ mục Index trong Python
Cơ chế Chỉ mục kép (Dual Indexing)

Minh họa cơ chế trỏ tới phần tử tương ứng trong bộ nhớ thông qua chỉ mục dương (ở trên) hoặc chỉ mục âm (ở dưới).

Positive:
Value:
"An"
"Bình"
"Cường"
"Dũng"
Negative:
>_ Bấm chỉ mục để truy cập 
# Khai báo danh sách học viên
students = ["An", "Bình", "Cường", "Dũng"]

# Truy cập bằng chỉ mục dương (Positive Index)
print(students[0]) # "An"
print(students[2]) # "Cường"

# Truy cập bằng chỉ mục âm (Negative Index)
print(students[-1]) # "Dũng" (phần tử cuối)
print(students[-3]) # "Bình"

# Vượt quá chỉ mục sẽ ném lỗi IndexError
# print(students[4]) -> IndexError: list index out of range

2. Duyệt qua các phần tử List - 2
Các phương pháp duyệt List thực tế
Loop Simulator (Duyệt phần tử)

Mô phỏng cơ chế duyệt tuần tự của vòng lặp qua các ô nhớ và in kết quả ra màn hình console giả lập.

"Táo"
"Ổi"
"Mận"
>_ Nhấn nút để khởi chạy... 
fruits = ["Táo", "Ổi", "Mận"]

# Cách 1: Duyệt trực tiếp (Khuyên dùng)
for fruit in fruits:
    print(fruit)

# Cách 2: Duyệt bằng chỉ mục qua range()
for i in range(len(fruits)):
    print(f"Vị trí {i} là quả {fruits[i]}")

# Cách 3: Duyệt bằng enumerate() (Pythonic Way)
for index, value in enumerate(fruits):
    print(f"STT {index + 1}: {value}")

3. Thao tác thêm phần tử - 1
Ba phương thức thêm phần tử vào List
Append O(1)
Thêm vào cuối danh sách

Phương thức append(item) chèn thẳng đối tượng vào vị trí cuối. Thao tác cực kỳ tối ưu, tốn thời gian cố định.

Insert O(n)
Chèn vào vị trí bất kỳ

Phương thức insert(index, item) chèn phần tử vào vị trí xác định, bắt buộc dịch chuyển toàn bộ phần tử phía sau sang phải.

Extend O(k)
Nối gộp danh sách khác

Phương thức extend(iterable) duyệt qua từng phần tử của danh sách mới để nạp vào cuối danh sách hiện tại.

3. Thao tác thêm phần tử - 2
Cơ chế thêm phần tử (Trực quan hóa)
Array Mô phỏng thêm phần tử

Thực thi các lệnh thêm phần tử và quan sát sự biến đổi phần tử trong bộ nhớ. 

numbers = [1, 2, 3]

# 1. Thêm vào cuối bằng append() -> O(1)
numbers.append(4)
print(numbers) # [1, 2, 3, 4]

# 2. Chèn 99 vào vị trí thứ 1 -> O(n)
numbers.insert(1, 99)
print(numbers) # [1, 99, 2, 3, 4]

# 3. Nối gộp danh sách bằng extend() -> O(k)
extra = [5, 6]
numbers.extend(extra)
print(numbers) # [1, 99, 2, 3, 4, 5, 6]

4. Thao tác cập nhật phần tử - 2
Cơ chế cập nhật giá trị (Trực quan hóa)
Slicing & Mutation Laboratory

Trực quan hóa hoạt động gán giá trị mới hoặc thay đổi lát cắt (slice) trên vùng bộ nhớ. 

fruits = ["Cam", "Quýt", "Mít", "Dừa"]

# 1. Cập nhật phần tử đơn lẻ qua index
fruits[1] = "Bưởi"
print(fruits) # ["Cam", "Bưởi", "Mít", "Dừa"]

# 2. Cập nhật hàng loạt bằng Slicing
fruits[2:4] = ["Sầu Riêng", "Vải"]
print(fruits) # ["Cam", "Bưởi", "Sầu Riêng", "Vải"]

# Slicing có thể mở rộng/thu hẹp mảng
fruits[0:2] = ["Măng Cụt"]
print(fruits) # ["Măng Cụt", "Sầu Riêng", "Vải"]

5. Thao tác xóa phần tử - 1
Các phương pháp xóa phần tử khỏi List
Remove O(n)
Xóa theo giá trị (Value)

Phương thức remove(val) quét tìm giá trị trùng khớp đầu tiên từ trái qua để xóa. Gây lỗi nếu giá trị không tồn tại.

Pop O(1)/O(n)
Xóa theo vị trí và thu hồi trị

Phương thức pop(index) xóa và trả ra giá trị. Pop phần tử cuối cùng cực nhanh O(1).

Del/Clear O(n)
Xóa theo lát cắt hoặc Xóa rỗng

Từ khóa del dùng để xóa vị trí/lát cắt trong khi clear() xóa sạch toàn bộ mảng.

5. Thao tác xóa phần tử - 2
Cơ chế xóa phần tử (Trực quan hóa)
Mô phỏng xóa phần tử

Trực quan hóa hoạt động xóa phần tử và sự tự động dịch chuyển vị trí của các phần tử phía sau. 

langs = ["Python", "Java", "C++", "JS"]

# 1. remove() xóa theo giá trị (Ném ValueError nếu thiếu)
if "Java" in langs:
    langs.remove("Java")

# 2. pop() xóa theo chỉ mục & trả về phần tử bị xóa
last = langs.pop()
print(last) # "JS"

# 3. del xóa theo lát cắt & clear() xóa sạch mảng
del langs[0] # Xóa "Python"
langs.clear() # Mảng trở về rỗng []

Tổng kết bài học - 1
Phép gán tham chiếu vs Sao chép đối tượng
Memory Mô phỏng tham chiếu RAM

Trực quan hóa sự khác biệt giữa phép gán tham chiếu (reference assignment) và sao chép đối tượng (object copying) trên RAM. 

# ❌ SAI LẦM PHỔ BIẾN: Chỉ gán tham chiếu bộ nhớ
a = [1, 2, 3]
b = a
b.append(99)
print(a) # Kết quả bị sửa đổi: [1, 2, 3, 99]

# ✅ GIẢI PHÁP ĐÚNG: Nhân bản đối tượng độc lập
a = [1, 2, 3]
c = a.copy() # hoặc c = a[:]
c.append(99)
print(a) # Nguyên bản an toàn: [1, 2, 3]
print(c) # Bản sao độc lập: [1, 2, 3, 99]

Tổng kết bài học - 2
Bảng tổng hợp đặc tính các thao tác List
Hành vi thao tác Cú pháp chính Thời gian (Time Complexity) Hành vi thay đổi gốc
Thêm vào cuối list.append(x) O(1) Thay đổi trực tiếp đối tượng gốc (In-place)
Chèn chỉ định list.insert(i, x) O(n) Dịch chuyển bộ nhớ (Các ô di chuyển sang phải)
Xóa theo trị list.remove(x) O(n) Quét tuần tự tìm phần tử khớp và xóa
Xóa và lấy về list.pop(i) O(1) phần tử cuối / O(n) phần tử đầu Xóa phần tử và thu hồi giá trị trả về
